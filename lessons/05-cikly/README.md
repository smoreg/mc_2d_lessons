# Урок 05. Циклы — повторяем действия 🔁

## 🎯 Цель урока

Научиться **повторять** действия много раз, не переписывая код руками. Хочешь поставить 10
блоков подряд? Не нужно писать 10 строк — достаточно одного **цикла**!

## 🤔 Робот-копатель

Представь робота в Майнкрафте, которому ты говоришь: «Поставь блок и сделай так **5 раз**».
Робот не спрашивает зачем — он просто повторяет. Цикл — это и есть такой робот: он повторяет
кусочек кода столько раз, сколько ты скажешь.

## 🧩 Новые слова

- **`for`** — повторяет код заранее известное число раз. Внутри скобок три части:
  с чего начать, до каких пор повторять, как меняться на каждом шаге.

```js
// i идёт от 1 до 5: 1, 2, 3, 4, 5
for (let i = 1; i <= 5; i = i + 1) {
  console.log("Ставлю блок номер", i);
}
```

> 💡 `i` — это **счётчик** (просто короткое имя, как «шаг номер i»). `i = i + 1` означает
> «увеличить счётчик на 1». Это так часто нужно, что есть короткая запись `i++` — то же самое!

- **`while`** — повторяет код, **пока** условие верно:

```js
let blocks = 3;
while (blocks > 0) {       // повторяем, пока блоки есть
  console.log("Поставил блок, осталось:", blocks);
  blocks = blocks - 1;     // не забудь уменьшать, иначе цикл не кончится!
}
```

## 🛠️ Что делаем

Открой `index.html` в браузере и загляни в консоль (**F12** → **Console**). Программа печатает
ряд блоков, строит лесенку, считает от 1 до N и показывает, как `while` ставит блоки, пока они
не закончатся.

## ✏️ Попробуй сам

1. Поменяй `i <= 5` на `i <= 10` — ряд блоков станет длиннее.
2. Сделай лесенку выше: пусть строит 7 ступенек вместо 4.
3. Напечатай числа **в обратном порядке** — от 10 до 1 (подсказка: `i = i - 1`).
4. С помощью `while` «съешь» 5 яблок: пока яблоки > 0, печатай «ням» и уменьшай счётчик.

## ⚠️ Частые ошибки

- В `while` обязательно **меняй** переменную внутри цикла (`blocks = blocks - 1`). Если забыть —
  условие всегда останется верным, и цикл будет крутиться **вечно** (браузер зависнет!).
- Не путай `<` и `<=`. `i <= 5` пройдёт по 1,2,3,4,5, а `i < 5` — только по 1,2,3,4.

## 💡 Запомни

- `for` — когда знаешь, **сколько раз** повторить.
- `while` — когда повторяешь, **пока** что-то верно.
- `i++` — короткая запись для «увеличить счётчик на 1».

В следующем уроке научимся создавать **свои команды** — функции. Например, команду «нанести
урон герою», которую можно вызывать сколько угодно раз! 🧩
