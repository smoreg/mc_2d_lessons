# Урок 03. Текст и общение с игроком 💬

## 🎯 Цель урока

Научиться работать с **текстом** (программисты говорят «строки»), склеивать его из кусочков и
даже **спрашивать игрока его имя**, чтобы потом поздороваться с ним по-настоящему.

## 🤔 Что такое строка?

Строка — это просто текст в кавычках: `"трава"`, `"Привет!"`, `"123"`. Представь бусины на
нитке: каждая буква — бусинка, а вся нитка целиком — это строка. Числа считают (`2 + 2 = 4`),
а строки **склеивают** (`"Майн" + "крафт" = "Майнкрафт"`). Склейка текста называется красивым
словом **конкатенация**.

## 🧩 Новые слова

- **Строка** — текст в кавычках. Можно в двойных `"..."`, можно в одинарных `'...'`.

```js
let blockName = "камень";   // строка
```

- **Склейка через `+`** — соединяет две строки в одну:

```js
let hello = "Привет, " + "герой!";   // получится "Привет, герой!"
```

- **Шаблонные строки** — удобный способ вставлять переменные прямо в текст. Пишутся в
  «обратных» кавычках `` ` `` (клавиша рядом с цифрой 1), а переменную вставляют через `${ }`:

```js
let name = "Стив";
console.log(`Привет, ${name}! Добро пожаловать в мир блоков.`);
// напечатает: Привет, Стив! Добро пожаловать в мир блоков.
```

- **`prompt("вопрос")`** — показывает окошко с вопросом и **возвращает** то, что игрок написал:

```js
let answer = prompt("Как тебя зовут?");   // ответ игрока попадёт в answer
```

## 🛠️ Что делаем

Открой `index.html` двойным щелчком. Программа спросит твоё имя в окошке — напиши его и нажми
«ОК». После этого она поздоровается с тобой по имени.

А чтобы увидеть все остальные сообщения, открой консоль: нажми **F12** и выбери вкладку
**Console**. Там программа показывает, как склеивается текст.

## ✏️ Попробуй сам

1. Поменяй текст вопроса в `prompt(...)` — например, спроси не имя, а любимый блок игрока.
2. Сделай так, чтобы программа спросила ещё и **возраст игрока** во второй переменной и вывела
   его в консоль.
3. Собери своё предложение из кусочков через `+`, например:
   `console.log("Я " + name + " и я люблю копать!");`
4. Перепиши это же предложение через шаблонную строку с `` `...${name}...` ``.

## ⚠️ Частые ошибки

- Не путай обычные кавычки `"..."` и обратные `` `...` ``. Вставлять `${ }` можно **только**
  в обратных.
- Если написать `2 + 2` — компьютер посчитает (`4`). А если `"2" + "2"` — он **склеит** строки
  и получится `"22"`! Числа в кавычках ведут себя как текст.

## 💡 Запомни

- Текст в кавычках — это **строка**.
- `+` для строк означает «склеить».
- Шаблонные строки `` `Привет, ${name}!` `` — самый удобный способ вставлять переменные в текст.
- `prompt()` спрашивает игрока и возвращает его ответ.

В следующем уроке научим программу **думать**: проверять, жив ли герой и хватает ли ему
ресурсов. Это называется «условия». 🤔
