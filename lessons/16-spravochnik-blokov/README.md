# Урок 16. Справочник блоков 📒

## 🎯 Цель урока

Перестать путаться в числах! Сейчас мы помним «1 — это трава, 3 — это камень» в голове. Это
неудобно и легко ошибиться. Заведём **справочник блоков** — словарь, где у каждого блока есть
номер, имя и цвет. И будем рисовать мир, беря цвет прямо из справочника.

## 🤔 Аналогия

Представь карточки в коробке. На каждой карточке написано: «Блок №1 — Трава — зелёный».
Когда тебе встретилось число 1, ты не вспоминаешь сам, а заглядываешь в карточку и читаешь
всё про этот блок. Справочник — это и есть коробка с такими карточками.

## 🧩 Новые слова

- **Объект `{ }`** — это «карточка» с подписанными свойствами. У свойства есть имя и значение:

```js
let grass = { id: 1, name: "Трава", color: "#5fbf4f", solid: true };
console.log(grass.name);  // "Трава"
console.log(grass.color); // "#5fbf4f"
```

- **`solid`** — свойство «твёрдый ли блок». Сквозь твёрдый (трава, земля, камень) пройти
  нельзя, а сквозь воздух — можно. Пригодится позже, когда герой будет ходить.

- **Объект-словарь** — большой объект, внутри которого лежат другие объекты-карточки:

```js
const BLOCKS = {
  AIR:   { id: 0, name: "Воздух", color: null,      solid: false },
  GRASS: { id: 1, name: "Трава",  color: "#5fbf4f", solid: true  },
  DIRT:  { id: 2, name: "Земля",  color: "#8b5a2b", solid: true  },
};
```

- **Функция-поиск `getBlockType(id)`** — по номеру находит нужную карточку, чтобы не писать
  кучу `if`.

## 🛠️ Что делаем

Открой `index.html`. Мы собрали справочник `BLOCKS` со всеми типами блоков. Сделали функцию
`getBlockType(id)`, которая по номеру возвращает карточку блока. Теперь рисование стало
короче: для каждой клетки берём цвет прямо из справочника, без длинной лесенки `if`. В консоли
программа печатает имена блоков.

## ✏️ Попробуй сам

1. В консоли посмотри: `console.log(getBlockType(3).name);` — что напечатает?
2. Поменяй цвет травы в справочнике на `"#7fe36a"` и обнови страницу.
3. Добавь в справочник новый блок, например `SAND: { id: 6, name: "Песок", color: "#e3d27a",
   solid: true }`, а потом поставь его в мир: `grid[4][1] = 6;`.
4. Напечатай имя блока, которого нет, например `getBlockType(99).name`. Функция вернёт воздух
   — мир не сломается.

## ⚠️ Частые ошибки

- К свойству обращаются через точку **без кавычек**: `grass.color`, а не `grass."color"`.
- Цвет воздуха у нас `null` (ничего) — такой блок мы просто не рисуем.

## 💡 Запомни

- **Объект** хранит несколько подписанных значений вместе.
- **Справочник** избавляет от запоминания «что есть что».
- `getBlockType(id)` достаёт всю информацию о блоке по его номеру.

В следующем уроке мы наведём порядок в рисовании: один короткий двойной цикл нарисует **весь
мир целиком**, беря цвета из справочника! 🖌️
