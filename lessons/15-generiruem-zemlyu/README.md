# Урок 15. Генерируем землю 🌍

## 🎯 Цель урока

Превратить пустой мир из воздуха в настоящий **ландшафт**: сверху небо, потом полоска травы,
под ней слой земли, а глубоко внизу — камень. Мир сам построится по правилам, которые мы
зададим.

## 🤔 Аналогия

Представь, что ты разрезал землю лопатой и смотришь на срез сбоку. Сверху — воздух (небо).
Потом тонкая полоска **травы**. Под ней — несколько слоёв **земли**. А ещё глубже начинается
твёрдый **камень**. Чем ниже клетка — тем «глубже» она в земле.

В нашей таблице чем **больше** число `y`, тем ниже клетка. Значит, по значению `y` мы можем
понять, что должно быть в клетке.

## 🧩 Новые слова

- **`if` внутри цикла** — мы уже знаем `if`. Теперь будем проверять `y` и решать, какой блок
  поставить:

```js
if (y < surface) {
  grid[y][x] = AIR;        // выше травы — небо
} else if (y === surface) {
  grid[y][x] = GRASS;      // ровно на поверхности — трава
} else if (y < surface + 4) {
  grid[y][x] = DIRT;       // чуть ниже — земля
} else {
  grid[y][x] = STONE;      // глубоко — камень
}
```

- **`surface`** — это просто переменная: на какой строке начинается трава («поверхность»).
- **`===`** — проверка «равно ли». `y === surface` значит «y ровно на поверхности».

## 🛠️ Что делаем

Открой `index.html`. Программа проходит **двойным циклом** по всем клеткам и для каждой решает
через `if`, что там должно быть, исходя из её высоты `y`. Получается слоёный мир. На холсте
ты увидишь этот мир, нарисованный простыми цветами.

## ✏️ Попробуй сам

1. Подними или опусти поверхность: поменяй `surface = 5` на другое число. Где станет больше
   неба, а где земли?
2. Сделай слой земли толще: вместо `surface + 4` поставь `surface + 6`. Камень начнётся ниже.
3. Поменяй цвет камня в коде (например, на `"#777777"`) и посмотри, как изменится мир.
4. Попробуй убрать строку с травой (`else if (y === surface)`), оставив только небо, землю и
   камень. Что получится?

## ⚠️ Частые ошибки

- Перепутать `<` и `<=`: из-за этого трава может «съесть» лишнюю строку или пропасть.
- Забыть `else` — тогда несколько условий сработают сразу и блок «перезапишется» не тем.

## 💡 Запомни

- Мир можно **построить по правилам**, проверяя высоту `y`.
- Двойной цикл + `if` = генерация ландшафта.
- Чем больше `y` — тем глубже клетка.

Сейчас мы пишем id блоков прямо числами (1, 2, 3). Это неудобно — легко забыть, что есть что.
В следующем уроке заведём **справочник блоков**, где у каждого блока будет имя и цвет! 📒
