# Урок 26. Копаем блоки ⛏️

## 🎯 Цель урока

Сделать так, чтобы по **левому клику** блок исчезал — как в настоящем Майнкрафте! Мы научимся
**менять мир**: записывать в нужную клетку воздух.

## 🤔 Аналогия

Мир — это таблица чисел. Каждое число — это блок: `1` трава, `2` земля, `3` камень, `0` воздух.
Копать — значит просто **заменить число в клетке на 0** (воздух). Блока больше нет, там пусто.
Это как стереть букву в клеточке тетради ластиком.

## 🧩 Новые слова

- **`getBlock(grid, x, y)`** — узнать, какой блок стоит в клетке.
- **`setBlock(grid, x, y, id)`** — поставить в клетку блок с номером `id`.
- **`digBlock(grid, x, y)`** — «копать»: если в клетке не воздух, ставим воздух (`0`).

```js
function digBlock(grid, x, y) {
  const id = getBlock(grid, x, y);
  if (id === 0) return null;   // там и так пусто — копать нечего
  setBlock(grid, x, y, 0);     // ставим воздух — блок исчез!
  return id;                   // вернём, что выкопали
}
```

> 💡 Функция возвращает `id` выкопанного блока. Позже, в уроках про инвентарь, мы будем
> добавлять выкопанное себе в сумку. А пока просто стираем блок.

## 🛠️ Что делаем

Открой `index.html`. Наведи мышку на любой блок и нажми **левую кнопку** — блок пропадёт!
Можешь прокопать целый тоннель. Справа вверху считается, сколько блоков ты выкопал.

## ✏️ Попробуй сам

1. Найди в `digBlock` строчку `setBlock(grid, x, y, 0)` и поменяй `0` на `3` — теперь вместо
   копания ты будешь превращать любой блок в камень. Верни обратно `0`, чтобы снова копать.
2. Сделай так, чтобы при копании в консоль печаталось `"Выкопал блок номер " + id`.
3. Добавь в мир побольше камня: поменяй условие генерации, чтобы камень начинался не с 9-й,
   а с 8-й строки.
4. Поменяй счётчик так, чтобы он считал не по 1, а по 2 за каждый блок.

## ⚠️ Частые ошибки

- Если кликнуть по **небу** (воздуху), копать нечего — функция вернёт `null`, и счётчик не
  должен увеличиваться. Проверь, что у тебя так и сделано.
- Не забывай менять именно `grid[y][x]` — сначала `y` (строка), потом `x` (столбец)!

## 💡 Запомни

- Копать = записать `0` (воздух) в клетку.
- `setBlock` меняет мир, `getBlock` только смотрит.
- Если копать нечего — функция возвращает `null`.
