# Урок 10. Объекты — описываем предмет 📦

## 🎯 Цель урока

До этого блок у нас был «размазан» по разным переменным: отдельно `x`, отдельно `y`,
отдельно цвет. Сегодня научимся **складывать всё про один блок в один свёрток** — это
называется **объект**. Так с блоками станет в сто раз удобнее работать.

## 🤔 Что такое объект?

Представь рюкзак с подписанными карманами. В кармане «x» лежит число 3, в кармане «y» —
число 5, в кармане «color» — цвет. Весь рюкзак — это один блок. **Объект** в JavaScript —
это такой рюкзак с подписанными карманами (они называются **свойства**).

```js
let block = { x: 3, y: 5, color: "#8b5a2b" };
```

## 🧩 Новые слова

- **Объект `{ }`** — набор пар «ключ: значение».

```js
let block = { x: 3, y: 5, color: "#8b5a2b" };
```

- **Доступ через точку** — чтобы заглянуть в карман, пишем имя объекта, точку и имя свойства:

```js
console.log(block.x);     // 3
console.log(block.color); // "#8b5a2b"
block.x = 10;             // можно и поменять значение в кармане
```

- **Функция `drawBlock(block)`** — наша команда «нарисуй блок». Она берёт объект и рисует
  его. Координаты в объекте — **в клетках**, поэтому умножаем на `TILE`, чтобы получить
  пиксели:

```js
function drawBlock(block) {
  ctx.fillStyle = block.color;
  ctx.fillRect(block.x * TILE, block.y * TILE, TILE, TILE);
}
```

## 🛠️ Что делаем

Открой `index.html` — на холсте появится блок земли. Но теперь он описан как **объект**
`{ x, y, color }`, а рисует его наша собственная функция `drawBlock`. Мы вызываем её для
нескольких блоков — и каждый встаёт на своё место.

## ✏️ Попробуй сам

1. Поменяй у блока цвет на камень `#9a9a9a` и координаты на `x: 4, y: 2`.
2. Создай свой блок-объект `let trava = { x: 1, y: 1, color: "#5fbf4f" };` и нарисуй его
   через `drawBlock(trava)`.
3. Нарисуй блок дерева и над ним блок листвы (одинаковый `x`, разный `y`).
4. Поменяй уже созданному блоку координату: `kamen.y = 6;` и нарисуй снова.

## ⚠️ Частые ошибки

- Между ключом и значением — **двоеточие**: `x: 3`, а пары разделяют запятыми.
- Координаты в объекте — **в клетках**, не в пикселях. Пиксели получаем умножением на `TILE`.
- К свойству обращаются через точку **без кавычек**: `block.x`, а не `block."x"`.

## 💡 Запомни

- Объект `{ }` хранит всё про один предмет вместе.
- `block.color` — заглянуть в карман; `block.color = ...` — положить туда новое.
- Клетки → пиксели: умножаем на `TILE`.

В следующем уроке мы соберём **много таких блоков в список** (массив) и нарисуем из них
настоящий кусочек мира! 🌍
