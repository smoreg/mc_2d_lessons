# Урок 07. Списки (массивы) 📋

## 🎯 Цель урока

Научиться хранить **много** значений в одной переменной — в **массиве** (списке). Например,
список всех блоков мира: трава, земля, камень. И научиться перебирать этот список циклом.

## 🤔 Сундук с ячейками

Представь сундук в Майнкрафте: внутри много ячеек, в каждой — свой предмет. Массив — это такой
сундук. У каждой ячейки есть **номер** (индекс), и по номеру можно достать предмет. Только
программисты считают ячейки **с нуля**: первая ячейка — номер 0!

## 🧩 Новые слова

- **Массив `[ ]`** — список значений через запятую в квадратных скобках:

```js
let world = ["трава", "земля", "камень"];
```

- **Индексы** — номер ячейки. Счёт идёт **с нуля**:

```js
console.log(world[0]);   // "трава"  - первый блок
console.log(world[1]);   // "земля"  - второй блок
console.log(world[2]);   // "камень" - третий блок
```

- **`.length`** — сколько всего элементов в массиве:

```js
console.log(world.length);   // 3
```

- **`.push()`** — добавляет новый элемент в **конец** списка:

```js
world.push("дерево");        // теперь в списке 4 блока
console.log(world.length);   // 4
```

- **Перебор циклом `for`** — пройтись по всем элементам по очереди:

```js
for (let i = 0; i < world.length; i++) {
  console.log("Блок", i, "это", world[i]);
}
```

> 💡 Обрати внимание: счётчик начинается с `0` и идёт `i < world.length` (меньше, не равно).
> Так мы пройдём по всем ячейкам от 0 до последней.

## 🛠️ Что делаем

Открой `index.html` в браузере и загляни в консоль (**F12** → **Console**). Программа создаёт
список блоков мира, добавляет новый блок через `.push()`, узнаёт длину списка и перебирает все
блоки циклом.

## ✏️ Попробуй сам

1. Добавь в массив `world` свои блоки: «песок», «вода», «алмаз». Используй `.push()`.
2. Напечатай **последний** блок списка (подсказка: индекс `world.length - 1`).
3. Сделай свой массив `tools = ["кирка", "топор", "лопата"]` и перебери его циклом.
4. Посчитай, сколько всего блоков в мире, и выведи: «В мире N блоков».

## ⚠️ Частые ошибки

- Счёт **с нуля**! Первый элемент — это `world[0]`, а не `world[1]`.
- Последний элемент — это `world[world.length - 1]`. Если написать `world[world.length]` —
  получишь `undefined` (такой ячейки нет).
- В цикле по массиву пиши `i < world.length` (меньше). С `<=` залезешь за край массива.

## 💡 Запомни

- Массив `[ ]` хранит много значений сразу.
- Индексы считаются **с нуля**: `world[0]` — первый.
- `.length` — длина списка, `.push()` — добавить в конец.
- Цикл `for` от 0 до `length` перебирает весь массив.
