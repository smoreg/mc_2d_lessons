# Урок 34. Сохраняем мир 💾

## 🎯 Цель урока

Научиться **сохранять** игру, чтобы она никуда не пропадала! Сегодня мы сделаем так, что
можно нажать кнопку «Сохранить» — и весь твой мир и инвентарь запишутся прямо в браузер.

## 🤔 Браузер умеет запоминать

Представь, что у браузера есть маленький **сундучок** с подписями. В этот сундучок можно
положить записку: «вот так выглядит мой мир». Сундучок не пропадёт, даже если ты закроешь
вкладку. Этот сундучок называется **`localStorage`** («локальное хранилище»).

Но есть одна хитрость: в сундучок можно класть **только текст**. А наш мир — это объект с
массивами, инвентарём и координатами героя. Поэтому сначала объект надо превратить в текст.
Этим занимается команда **`JSON.stringify`** (читается «джейсон-стрингифай») — она берёт
объект и записывает его одной длинной строкой.

## 🧩 Новые слова

- **`JSON.stringify(объект)`** — превращает объект в **текст**.

```js
let data = { x: 5, y: 10 };
let text = JSON.stringify(data);   // получится строка: '{"x":5,"y":10}'
console.log(text);
```

- **`localStorage.setItem(ключ, текст)`** — кладёт текст в сундучок под подписью (ключом).

```js
localStorage.setItem('mc2d-save', text);   // сохранили под именем 'mc2d-save'
```

- **Ключ** — это просто имя-подпись, по которой потом найдём нашу запись. У нас ключ всегда
  один и тот же: `'mc2d-save'`.

> 💡 Сначала собираем всё в один объект, потом `JSON.stringify` превращает его в текст,
> и только потом `setItem` кладёт этот текст в хранилище. Три шага!

## 🛠️ Что делаем

Открой `index.html`. Это уже знакомая игра: ходишь, копаешь, ставишь блоки. Но теперь у неё
есть **память**! Накопай ям, настрой башен — и нажми клавишу **S** (или кнопку «💾 Сохранить»).
В уголке появится «Игра сохранена ✅». Всё! Мир записан в сундучок браузера.

Вот как это устроено в коде:

```js
// Собираем всё состояние игры в один объект
const state = {
  world: { cols: world.cols, rows: world.rows, grid: world.grid },
  inventory: inventory,
  player: { x: player.x, y: player.y },
};
const text = JSON.stringify(state);          // объект → текст
localStorage.setItem('mc2d-save', text);     // текст → в сундучок
```

## ✏️ Попробуй сам

1. Накопай несколько блоков, нажми **S** и открой консоль (F12 → Console) — там видно
   сохранённый текст. Найди в нём координаты героя!
2. Поменяй сообщение `'Игра сохранена ✅'` на своё, например `'Мир в безопасности! 🛡️'`.
3. Добавь `console.log(text)` сразу после `JSON.stringify` — посмотри, как мир выглядит в виде
   текста. Длинная строка, правда?
4. Загляни в хранилище браузера: F12 → вкладка **Application** (или **Хранилище**) →
   **Local Storage** → найди ключ `mc2d-save`.

## ⚠️ Частые ошибки

- В сундучок можно класть **только текст**. Если попробовать положить объект напрямую без
  `JSON.stringify`, браузер запишет странную строку `[object Object]` — мир потеряется.
- Ключ — это **текст в кавычках**: `'mc2d-save'`, а не `mc2d-save` без кавычек.

## 💡 Запомни

- **`localStorage`** — сундучок браузера, который помнит данные даже после закрытия вкладки.
- **`JSON.stringify(объект)`** превращает объект в текст.
- **`localStorage.setItem(ключ, текст)`** кладёт текст в сундучок.

сохранение, чтобы мир возвращался даже после перезапуска страницы! 🚀
