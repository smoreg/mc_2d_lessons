# Урок 23. Гравитация и прыжок 🦘

## 🎯 Цель урока

Сделать так, чтобы герой **падал вниз** (как всё в нашем мире) и умел **прыгать**. Для этого мы
познакомимся со «скоростью» героя по вертикали и с гравитацией. Это самый «физичный» урок —
будет интересно!

## 🤔 Что такое гравитация?

Подбрось мячик вверх. Сначала он летит быстро, потом всё медленнее, на секунду замирает в
самой верхней точке и начинает падать вниз — сначала медленно, а потом всё быстрее. Это
притяжение Земли, **гравитация**.

Как это запрограммировать? У героя будет своя **скорость по вертикали** — назовём её `vy`
(velocity по Y). И есть правило:

> Каждый кадр гравитация чуть-чуть **прибавляет** к `vy` (тянет вниз).
> А положение героя `y` меняется на величину `vy`.

Если `vy` отрицательная — герой летит **вверх** (прыгает). Гравитация постепенно уменьшает
эту скорость, останавливает героя в высшей точке и разгоняет вниз. Точь-в-точь как мячик!

## 🧩 Новые слова

- **`vy` — скорость героя по вертикали.** Положительная — падает вниз, отрицательная — летит
  вверх. Добавим её в объект героя:

```js
let player = { x: 5, y: 1, vy: 0, onGround: false, width: 0.8, height: 1.8 };
```

- **`gravity` — гравитация.** Маленькое число, которое каждый кадр прибавляется к `vy`:

```js
const gravity = 0.04;
player.vy += gravity;     // гравитация тянет вниз
player.y  += player.vy;   // двигаем героя на его вертикальную скорость
```

- **`jumpPower` — сила прыжка.** Прыжок — это резкий толчок **вверх**, поэтому мы задаём `vy`
  большим **отрицательным** числом:

```js
const jumpPower = 0.5;
player.vy = -jumpPower;    // прыгнули вверх
```

- **`onGround` — стоит ли герой на земле.** Прыгать можно только когда стоишь на земле, а не в
  воздухе (иначе получится бесконечный полёт). Это значение `true` или `false`.

## 🛠️ Что делаем

Открой `index.html`, кликни по странице. Герой начнёт **падать** сверху и приземлится на «пол»
(пока это просто нижняя граница холста — настоящие столкновения с блоками будут в следующем
уроке). Нажми ↑ или пробел — герой **подпрыгнет**! Ходить ← → тоже можно.

Обрати внимание на порядок в `update()`: сначала гравитация прибавляется к `vy`, потом `vy`
прибавляется к `y`, и только потом проверяем, не уткнулись ли в пол.

## ✏️ Попробуй сам

1. Сделай гравитацию слабее: `const gravity = 0.02;`. Герой будет падать как на Луне!
2. Сделай прыжок выше: `const jumpPower = 0.8;`. А теперь совсем слабенький: `0.2`.
3. Сильная гравитация `0.1` + мощный прыжок `0.7` — получится резкий «скачущий» герой.
4. Подними «пол» повыше: в коде найди переменную `floorY` и уменьши её — герой будет
   приземляться раньше.

## ⚠️ Частые ошибки

- Прыжок — это **отрицательная** `vy` (`vy = -jumpPower`), потому что на экране ось Y растёт
  **вниз**: чем меньше `y`, тем выше герой.
- Без проверки `onGround` герой сможет прыгать прямо в воздухе и улетит в космос. Прыжок
  разрешаем только когда `onGround === true`.
- Не забывай **обнулять `vy`** при приземлении, иначе скорость падения будет копиться.

## 💡 Запомни

- **`vy`** — вертикальная скорость; **гравитация** каждый кадр прибавляет к ней.
- **Прыжок** = задать `vy` большим **отрицательным** числом.
- Прыгать можно только когда **`onGround`** = `true`.

по-настоящему **сталкиваться с блоками**: стоять на земле, не проваливаться и не проходить
сквозь стены! 🧱
