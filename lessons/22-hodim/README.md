# Урок 22. Ходим влево-вправо 🏃

## 🎯 Цель урока

Оживить героя! Теперь по нажатию стрелок ← и → он будет **двигаться** по миру. Мы соединим то,
что узнали раньше: память о клавишах (`keys`) и игровой цикл, который рисует кадры.

## 🤔 Как получается движение?

Мультик — это много картинок, которые быстро сменяют друг друга. В игре то же самое: каждый
кадр мы чуть-чуть меняем координату героя и перерисовываем его. Глаз видит это как плавное
движение.

Главная мысль: **в каждом кадре проверяем, какие стрелки зажаты, и сдвигаем `player.x`**.

```
Стрелка → зажата?  → player.x = player.x + скорость   (едем вправо)
Стрелка ← зажата?  → player.x = player.x - скорость   (едем влево)
```

## 🧩 Новые слова

- **`speed` — скорость.** Это число, на которое герой сдвигается за один кадр. Сделаем
  небольшим, чтобы движение было плавным:

```js
const speed = 0.12;   // на сколько клеток сдвигаемся за кадр
```

- **Изменение координаты в цикле.** Внутри игрового цикла каждый кадр проверяем клавиши:

```js
if (keys['ArrowRight']) player.x = player.x + speed;  // вправо
if (keys['ArrowLeft'])  player.x = player.x - speed;  // влево
```

Можно записать короче с помощью `+=` и `-=`:

```js
if (keys['ArrowRight']) player.x += speed;  // то же самое
if (keys['ArrowLeft'])  player.x -= speed;
```

> 💡 `player.x += speed` читается как «прибавь speed к player.x». Очень удобная короткая запись!

## 🛠️ Что делаем

Открой `index.html`, кликни по странице и нажимай ← и →. Герой поедет по травке! Мы вынесли
управление в отдельную функцию `update()` — она отвечает за «что меняется», а `drawWorld()` и
`drawPlayer()` — за «что рисуем». Так код понятнее.

Ещё мы добавили простую защиту, чтобы герой не убежал за край экрана.

## ✏️ Попробуй сам

1. Сделай героя быстрее: поставь `const speed = 0.25;`. А теперь медленнее: `0.05`. Найди
   скорость, которая нравится тебе.
2. Добавь движение вверх-вниз по стрелкам ↑ и ↓ (меняй `player.y`). Это «полёт» — пока без
   гравитации.
3. Сделай так, чтобы при нажатии пробела герой делал большой «рывок» вправо (сразу
   `player.x += 1`). Подсказка: используй `keys[' ']`.
4. Поменяй размер мира: добавь столбцы в массив `world` и сделай героя «путешественником».

## ⚠️ Частые ошибки

- Менять `player.x` нужно **внутри игрового цикла** (в `update`), а не один раз при загрузке —
  иначе герой дёрнется и встанет.
- Не делай `speed` слишком большим (например, `5`) — герой будет «телепортироваться»
  скачками, а не плавно идти.

## 💡 Запомни

- Движение = **каждый кадр чуть-чуть меняем координату** и перерисовываем.
- **`speed`** — насколько сдвигаемся за один кадр.
- **`+=`** и **`-=`** — короткая запись «прибавить/отнять к переменной».

Герой ходит, но он словно в невесомости — висит в воздухе. В следующем уроке добавим
**гравитацию**: он будет падать вниз и научится **прыгать**! 🦘
