# Урок 02. Переменные и числа 🔢

## 🎯 Цель урока

Научиться **запоминать** числа в программе — например, здоровье героя, количество очков или
число собранных блоков. Для этого есть **переменные**.

## 🤔 Что такое переменная?

Представь коробку с подписью. В коробку можно что-нибудь положить, а по подписи — найти.
**Переменная** — это такая коробка в памяти компьютера. У неё есть **имя** (подпись) и
**значение** (то, что лежит внутри).

```js
let health = 100;   // коробка с именем health, внутри число 100
```

## 🧩 Новые слова

- **`let`** — создаёт переменную, значение которой можно **менять**.
- **`const`** — создаёт переменную, значение которой менять **нельзя** (постоянная).
- **Арифметика** — компьютер умеет считать:
  - `+` сложить, `-` вычесть, `*` умножить, `/` разделить.

```js
let score = 0;       // очки
score = score + 10;  // прибавили 10 очков, теперь score = 10
```

> 💡 Запись `score = score + 10` читается так: «возьми старое значение score, прибавь 10 и
> положи результат обратно в score». Это очень частый приём в играх!

## 🛠️ Что делаем

Открой `index.html` в браузере и загляни в консоль (F12 → Console). Программа создаёт героя со
здоровьем и очками, наносит ему урон, даёт очки за добычу блоков и печатает результат.

## ✏️ Попробуй сам

1. Поменяй начальное здоровье героя `let health = 100;` на `let health = 50;`.
2. Сделай так, чтобы за каждый блок давали не 10, а 25 очков.
3. Добавь свою переменную, например `let blocksMined = 3;` (накопано блоков) и выведи её в
   консоль через `console.log`.
4. Попробуй посчитать что-нибудь: `console.log(2 * 8);` — компьютер как калькулятор!

## ⚠️ Частые ошибки

- Имя переменной пишется **без кавычек**: `let health = 100;` — правильно;
  `let "health" = 100;` — ошибка.
- А вот **текст** всегда в кавычках: `"Привет"`.
- Переменную нужно сначала **создать** (`let`), а потом уже использовать.

## 💡 Запомни

- `let` — можно менять, `const` — нельзя.
- Числа пишут **без кавычек**.
- `score = score + 10` — стандартный способ «прибавить к переменной».

В следующем уроке поработаем с **текстом** (строками) и научимся спрашивать у игрока его имя!
