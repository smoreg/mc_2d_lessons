# Урок 30. Считаем добычу 📊

## 🎯 Цель урока

Научиться вести **счёт ресурсов**: сколько земли, сколько камня, сколько дерева ты накопал.
Для этого мы возьмём один объект-«блокнот» и будем дописывать в него числа.

## 🤔 Объект — это блокнот с подписями

Представь блокнот, где на каждой строчке своя подпись и число:

```
земля:  5
камень: 2
дерево: 0
```

В JavaScript такой блокнот называется **объект**. У него есть **свойства** (подписи) и их
**значения** (числа). Один объект может хранить сразу много чисел — удобно!

## 🧩 Новые слова

- **Объект `{ }`** — коробка, в которой лежат не просто значения, а пары «имя → значение».

```js
const resources = { dirt: 0, stone: 0, wood: 0 };  // блокнот для подсчёта
```

- **Чтение свойства** — берём число по имени:

```js
console.log(resources.dirt);   // 0
```

- **Запись свойства** — кладём новое число по имени:

```js
resources.dirt = 5;            // теперь земли 5
resources.dirt += 1;           // стало 6 (прибавили 1)
```

> 💡 `resources.dirt += 1` — это короткая запись для `resources.dirt = resources.dirt + 1`.
> Очень частый приём: «увеличить счётчик на единицу».

## 🛠️ Что делаем

Открой `index.html`. Ты увидишь маленький мир из блоков. **Кликни** по любому блоку — он
«добывается», исчезает, а нужный счётчик в объекте `resources` увеличивается на 1. Сверху на
экране (и в консоли) видно, сколько чего ты уже накопал.

## ✏️ Попробуй сам

1. Накопай 5 блоков земли и посмотри, как меняется число `dirt` на экране.
2. В коде поменяй начальные значения: `const resources = { dirt: 100, stone: 0, wood: 0 };` —
   и убедись, что земля стартует со 100.
3. Добавь в объект новое свойство, например `sand: 0`, и научи код считать песок.
4. Выведи в консоль общее число накопанных блоков: `console.log(resources.dirt + resources.stone + resources.wood);`.

## ⚠️ Частые ошибки

- Свойство пишется **через точку без кавычек**: `resources.dirt` — правильно;
  `resources."dirt"` — ошибка.
- Не забывай создать свойство в объекте, прежде чем к нему прибавлять. Если свойства нет,
  `resources.gold += 1` даст `NaN` («не число»).

## 💡 Запомни

- Объект `{ }` хранит много значений с подписями (свойствами).
- `obj.имя` — прочитать; `obj.имя = ...` — записать; `obj.имя += 1` — увеличить счётчик.
