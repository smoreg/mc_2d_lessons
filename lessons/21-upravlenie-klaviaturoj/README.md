# Урок 21. Управление с клавиатуры ⌨️

## 🎯 Цель урока

Научить программу **слушать клавиатуру**: понимать, какую клавишу ты нажал и какую отпустил.
Пока герой ещё не двигается — но программа уже будет знать, какие стрелки нажаты прямо сейчас.
Это основа управления в любой игре!

## 🤔 Как программа узнаёт о нажатиях?

Представь, что ты сидишь спиной к двери. Сам ты не видишь, кто вошёл. Но если повесить
**звоночек**, то при каждом входе он зазвенит — и ты узнаешь о событии.

В программировании такой «звоночек» называется **обработчик события**. Мы говорим браузеру:
«Когда нажмут клавишу — вызови вот эту функцию». Это называется *подписаться на событие*.

Главных событий два:
- **`keydown`** — клавишу **нажали**;
- **`keyup`** — клавишу **отпустили**.

## 🧩 Новые слова

- **`addEventListener('событие', функция)`** — подписаться на событие. Браузер сам будет
  вызывать твою функцию, когда событие случится.

```js
window.addEventListener('keydown', function (e) {
  console.log('Нажали клавишу:', e.key);
});
```

- **`e.key`** — внутри функции нам приходит «письмо» о событии (мы называем его `e`).
  У него есть свойство `key` — название нажатой клавиши: `"ArrowLeft"`, `"ArrowRight"`,
  `"ArrowUp"`, `" "` (это пробел) и так далее.

- **Объект `keys` — память о нажатых клавишах.** Событие `keydown` срабатывает в момент
  нажатия. Но в игре нам нужно знать: *прямо сейчас* клавиша всё ещё зажата или уже нет?
  Поэтому заведём объект-«доску», где будем отмечать состояние каждой клавиши:

```js
let keys = {};                  // пустая доска
keys['ArrowRight'] = true;      // отметили: правая стрелка зажата
keys['ArrowRight'] = false;     // отметили: отпустили
```

## 🛠️ Что делаем

Открой `index.html` и **кликни по странице мышкой** (чтобы она "слушала" клавиатуру). Теперь
нажимай стрелки ← ↑ → ↓ и пробел. Под холстом ты увидишь список клавиш, которые зажаты прямо
сейчас. Загляни и в консоль (F12 → Console) — там печатается каждое нажатие.

Герой пока стоит на месте: мы только **запоминаем** нажатия. Двигать его будем в следующем
уроке.

## ✏️ Попробуй сам

1. Нажми сразу несколько стрелок одновременно — увидишь, что в `keys` отмечаются все.
2. Добавь в консоль сообщение и для отпускания: внутри обработчика `keyup` напиши
   `console.log('Отпустили:', e.key);`.
3. Узнай название любой клавиши: нажми букву или цифру и посмотри в консоли, что покажет
   `e.key`.
4. Сделай так, чтобы при нажатии пробела (`' '`) в консоль писалось «Прыжок!».

## ⚠️ Частые ошибки

- Названия стрелок пишутся **точно так**: `"ArrowLeft"`, `"ArrowRight"`, `"ArrowUp"`,
  `"ArrowDown"`. С большой буквы и без пробелов. Пробел — это просто `" "`.
- Если нажатия не ловятся — кликни мышкой по странице/холсту, чтобы он стал «активным».

## 💡 Запомни

- **`addEventListener`** — подписаться на событие («повесить звоночек»).
- **`keydown`** — нажали, **`keyup`** — отпустили.
- **`e.key`** — название клавиши.
- Объект **`keys`** помнит, какие клавиши зажаты прямо сейчас.

Программа уже «слышит» клавиатуру. В следующем уроке мы наконец **сдвинем героя** влево и
вправо по нажатию стрелок! 🏃
