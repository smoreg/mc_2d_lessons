# Урок 13. Сетка и координаты 🗺️

## 🎯 Цель урока

В Майнкрафте мир состоит из ровных клеток. Сегодня мы нарисуем **сетку** на холсте,
научимся переводить координаты **клетка ↔ пиксели** и сделаем так, чтобы клетка под
курсором мыши **подсвечивалась**. Это та самая магия, которая потом позволит копать и
ставить блоки именно туда, куда ты целишься!

## 🤔 Зачем переводить клетки в пиксели и обратно?

Компьютер рисует в **пикселях** (мелких точках), а нам удобнее думать в **клетках**
(блок 1, блок 2...). Поэтому:

- чтобы нарисовать клетку — переводим клетку в пиксели: `x * TILE`;
- чтобы понять, на какую клетку показывает мышь — переводим пиксели в клетку:
  `Math.floor(px / TILE)`.

`Math.floor` округляет **вниз**: например `Math.floor(70 / 32)` = `Math.floor(2.18)` = `2`.
То есть пиксель 70 попадает в клетку номер 2.

## 🧩 Новые слова

- **`ctx.strokeStyle` и `ctx.strokeRect(x, y, w, h)`** — рисуют **контур** (рамку)
  прямоугольника, а не заливку.

```js
ctx.strokeStyle = "#88aa88";
ctx.strokeRect(0, 0, TILE, TILE); // рамка одной клетки
```

- **`Math.floor(число)`** — округляет вниз. Превращает пиксели в номер клетки.

```js
let col = Math.floor(px / TILE); // номер клетки по горизонтали
let row = Math.floor(py / TILE); // номер клетки по вертикали
```

- **Событие мыши `mousemove`** — срабатывает, когда мышь двигается над холстом.
  `e.offsetX` и `e.offsetY` — координаты мыши **внутри холста** (в пикселях).

```js
canvas.addEventListener("mousemove", function (e) {
  let col = Math.floor(e.offsetX / TILE);
  let row = Math.floor(e.offsetY / TILE);
});
```

## 🛠️ Что делаем

Открой `index.html` и **поводи мышкой** по холсту. Ты увидишь сетку из клеток, а клетка
под курсором подсветится жёлтым. Внизу будет видно номер клетки (колонку и ряд) — это
координаты в клетках, как в настоящем Майнкрафте.

## ✏️ Попробуй сам

1. Поменяй цвет подсветки клетки на свой любимый.
2. Сделай клетки крупнее — поставь `const TILE = 48;` (сетка перестроится сама).
3. Поменяй цвет линий сетки `strokeStyle` на более тёмный или светлый.
4. Сложно: вместо подсветки рисуй в клетке под мышью маленький блок земли `#8b5a2b`.

## ⚠️ Частые ошибки

- `strokeRect` рисует **рамку**, а `fillRect` — **заливку**. Не перепутай.
- Для перевода пикселей в клетку обязательно `Math.floor`, иначе получится дробь.
- `e.offsetX/offsetY` — координаты именно внутри холста; не путай их с координатами на
  всей странице.

## 💡 Запомни

- Клетка → пиксели: умножаем на `TILE`.
- Пиксели → клетка: делим на `TILE` и берём `Math.floor`.
- Событие `mousemove` + `e.offsetX/offsetY` говорят, где сейчас мышь.
