# Урок 19. Простые текстуры 🎨

## 🎯 Цель урока

Сделать блоки красивыми! Сейчас это просто одноцветные квадраты. Добавим мелкие детали:
тёмную обводку у каждого блока, травинки на траве, камешки-крапинки на камне. Так мир станет
гораздо приятнее на вид — почти как в настоящем Майнкрафте.

## 🤔 Аналогия

Представь, что ты раскрасил квадрат одной краской — скучновато. А теперь возьми тонкую
кисточку и добавь чёрточки, точки, обводку. Сразу видно: это трава, это камень! **Текстура** —
это и есть такие мелкие детали поверх основного цвета.

## 🧩 Новые слова

- **`ctx.strokeStyle`** — цвет линии (контура), которой рисуем.
- **`ctx.strokeRect(x, y, w, h)`** — рисует **рамку** прямоугольника (не закрашенную, только
  контур). Отлично подходит для обводки блока:

```js
ctx.strokeStyle = "#000000";
ctx.strokeRect(x * TILE, y * TILE, TILE, TILE); // тонкая чёрная рамка
```

- **`ctx.lineWidth`** — толщина линии в пикселях.
- Точки и полоски мы рисуем теми же `fillRect` — просто маленькими прямоугольниками поверх
  блока.

## 🛠️ Что делаем

Открой `index.html`. Теперь рисование каждого блока состоит из двух шагов: сначала
закрашиваем квадрат основным цветом, потом добавляем детали. У всех блоков — лёгкая обводка,
чтобы их было видно по отдельности. У травы сверху торчат травинки, а на камне — тёмные
крапинки. Сравни с прошлым уроком — стало гораздо живее!

## ✏️ Попробуй сам

1. Сделай обводку светлее или толще: поменяй `ctx.lineWidth = 1;` на `2` и цвет обводки.
2. Добавь точку-«семечко» на землю: в ветке для земли нарисуй маленький тёмный квадратик
   через `fillRect`.
3. Сделай больше травинок: добавь ещё несколько `fillRect` с разными сдвигами по `x`.
4. Поменяй цвет крапинок на камне на более светлый, например `"#bdbdbd"`.

## ⚠️ Частые ошибки

- Сначала **заливка**, потом **детали**. Если нарисовать детали первыми, заливка их закрасит.
- Координаты деталей считают **относительно угла блока**: `px = x * TILE`, а потом прибавляют
  небольшой сдвиг (например, `px + 6`).

## 💡 Запомни

- **`fillRect`** закрашивает, **`strokeRect`** обводит контуром.
- Текстура — это **мелкие детали поверх** основного цвета.
- Рисуем по порядку: заливка → детали.
