# Урок 33. Трата и пополнение ⛏️🧱

## 🎯 Цель урока

Соединить инвентарь с миром! Теперь:

- **копнул блок** → он попадает в инвентарь (число растёт);
- **поставил блок** → он берётся из выбранного слота (число падает);
- ставить можно, **только если** в выбранном слоте есть блоки.

Это и есть настоящий игровой цикл «добываю — строю», как в Майнкрафте.

## 🤔 Как это работает

Инвентарь — это «склад». Копаешь — на склад **приходит** товар. Строишь — со склада товар
**уходит**. А если склад по нужному блоку пуст — построить нечем, и игра тебе не даст.

## 🧩 Новые слова

- **`addBlock(inv, blockId, amount)`** — кладёт блоки в инвентарь (мы уже его знаем).
- **`removeFromSelected(inv)`** — убирает **один** блок из выбранного слота. Возвращает id
  убранного блока или `null`, если слот был пуст:

```js
function removeFromSelected(inv) {
  const slot = inv.slots[inv.selected];
  if (!slot || slot.count <= 0) return null;   // слот пуст — ставить нечего
  const id = slot.blockId;
  slot.count -= 1;                              // потратили один
  if (slot.count === 0) slot.blockId = 0;       // слот опустел
  return id;
}
```

- **Левая и правая кнопки мыши** — у события мыши есть `e.button`: `0` — левая, `2` — правая.
  Левой будем **копать**, правой — **ставить**.

## 🛠️ Что делаем

Открой `index.html`. Управление:

- **Левый клик** по блоку — копаешь: блок исчезает, а в инвентаре нужного блока становится
  больше.
- **Клавиши 1–8** — выбираешь, какой блок «в руке».
- **Правый клик** по пустому месту — ставишь выбранный блок: в мире появляется новый блок, а
  в инвентаре его становится на один меньше. Если в слоте 0 — поставить нельзя.

Понаблюдай, как числа в слотах то растут (копаешь), то уменьшаются (строишь)!

## ✏️ Попробуй сам

1. Накопай побольше камня (левый клик по серым блокам) и построй из него башню (правый клик).
2. Опустоши какой-нибудь слот до нуля и попробуй им строить — игра не даст. Почему? Потому что
   `removeFromSelected` вернул `null`.
3. В коде поменяй стартовый инвентарь: дай герою сразу 50 земли.
4. Сделай так, чтобы при попытке поставить из пустого слота печаталось сообщение в консоль.

## ⚠️ Частые ошибки

- Перед постановкой обязательно проверяй результат `removeFromSelected`: если он `null` —
  блок ставить **нельзя**, слот пуст.
- Правый клик в браузере открывает своё меню — мы его выключаем строкой
  `e.preventDefault()` в обработчике `contextmenu`.

## 💡 Запомни

- Копаю → `addBlock` (пополнение). Строю → `removeFromSelected` (трата).
- Ставить можно, только если в выбранном слоте есть блоки.
