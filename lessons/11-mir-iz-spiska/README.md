# Урок 11. Рисуем мир из списка блоков 🌍

## 🎯 Цель урока

Теперь у нас есть блоки-объекты и функция `drawBlock`. Соединим их с тем, что мы уже
знаем про **массивы** (списки), и нарисуем целый **кусочек мира** одним коротким циклом.
Это уже почти настоящий Майнкрафт!

## 🤔 Что такое массив объектов?

Раньше массив хранил числа или цвета. Но в коробку-список можно положить и **целые
блоки-объекты**! Получится список рюкзаков: первый блок, второй, третий... А чтобы
нарисовать их все — просто пройдёмся по списку циклом и каждый отдадим в `drawBlock`.

```js
let world = [
  { x: 0, y: 8, color: "#8b5a2b" },
  { x: 1, y: 8, color: "#8b5a2b" },
];
```

## 🧩 Новые слова

- **Массив объектов** — список, в котором лежат блоки:

```js
let world = [
  { x: 0, y: 8, color: "#5fbf4f" },
  { x: 1, y: 8, color: "#5fbf4f" },
];
```

- **Перебор циклом `for`** — берём блок за блоком по их номеру:

```js
for (let i = 0; i < world.length; i = i + 1) {
  let block = world[i]; // блок номер i
  drawBlock(block);     // и рисуем его
}
```

- **`world.length`** — сколько всего блоков в списке. Удобно: цикл сам подстроится,
  даже если ты добавишь новые блоки.

## 🛠️ Что делаем

Открой `index.html` — увидишь маленький мир: ряд земли внизу (это пол), сверху на нём
трава, а ещё пара блоков камня. Весь мир хранится в массиве `world`, а рисуется одним
циклом. Хочешь больше блоков — просто допиши их в список!

## ✏️ Попробуй сам

1. Добавь в массив `world` ещё один блок камня с другими координатами.
2. Построй маленькое дерево: блок ствола `#7a4a1e` и блок листвы `#3e9b3e` над ним.
3. Сделай пол длиннее — добавь ещё несколько блоков земли вправо.
4. Сложно: добавь блоки земли **циклом**, чтобы не писать каждый руками (подсказка:
   в цикле делай `world.push({ x: i, y: 9, color: "#8b5a2b" });`).

## ⚠️ Частые ошибки

- Блоки в массиве разделяются **запятыми**.
- Цикл идёт до `world.length`, а не до фиксированного числа — тогда он не сломается,
  когда блоков станет больше.
- Внутри цикла сначала берём блок `world[i]`, потом рисуем — не путай номер и сам блок.

## 💡 Запомни

- В массив можно складывать целые объекты-блоки.
- Один цикл рисует **сколько угодно** блоков.
- `world.length` — длина списка; цикл подстраивается сам.
