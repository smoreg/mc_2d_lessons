# Урок 36. День и ночь + мелочи 🌙

## 🎯 Цель урока

Оживить мир: пусть небо **плавно темнеет ночью и светлеет днём**, прямо как в настоящем
Майнкрафте. Для этого мы заведём **таймер времени** и научимся **смешивать цвета**.

## 🤔 Как сделать «плавно»?

В прошлых уроках цвет неба был всегда один и тот же — `'#9bd3ff'`. А что если бы он медленно
превращался в тёмно-синий ночной, а потом обратно?

Представь, что у тебя есть две банки краски: дневная (светло-голубая) и ночная (тёмно-синяя).
Если налить **половину** одной и **половину** другой — получится что-то среднее, сумеречное.
Если взять **чуть-чуть** ночной и **много** дневной — будет почти день. Так и работает плавный
переход: мы каждый кадр чуть-чуть меняем «сколько ночной краски подмешать».

Это смешивание называется **интерполяция** (страшное слово, а смысл простой: «найти значение
посередине»).

## 🧩 Новые слова

- **Таймер времени** — обычная переменная-счётчик, которую мы каждый кадр чуть увеличиваем.

```js
let time = 0;
time += 0.005;     // каждый кадр время чуть-чуть идёт вперёд
```

- **`Math.sin(time)`** — волшебная функция, которая плавно качается от `-1` до `1` и обратно,
  как качели. Идеально, чтобы делать что-то «туда-сюда» (день → ночь → день).

```js
let day = (Math.sin(time) + 1) / 2;   // получится число от 0 (ночь) до 1 (день)
```

- **Смешивание чисел (интерполяция)** — берём начало `a`, конец `b` и долю `t` от 0 до 1:

```js
// t = 0 → получим a, t = 1 → получим b, t = 0.5 → ровно посередине
function mix(a, b, t) {
  return Math.round(a + (b - a) * t);
}
```

- **Цвет из трёх чисел** — цвет можно собрать из красного, зелёного и синего:
  `rgb(красный, зелёный, синий)`, каждое число от 0 до 255.

```js
ctx.fillStyle = 'rgb(' + r + ',' + g + ',' + b + ')';
```

## 🛠️ Что делаем

Открой `index.html` и просто понаблюдай: небо медленно темнеет, как будто наступает вечер,
потом ночь, а потом снова светает. Можешь ходить и копать, как обычно — а небо живёт своей
жизнью.

Вот сердце урока:

```js
// дневной и ночной цвета (красный, зелёный, синий)
const dayColor   = [155, 211, 255];   // #9bd3ff — светло-голубой
const nightColor = [12, 18, 54];      // тёмно-синий

let time = 0;

function skyColor() {
  time += 0.004;                              // время идёт
  const day = (Math.sin(time) + 1) / 2;       // 0 = ночь, 1 = день
  const r = mix(nightColor[0], dayColor[0], day);
  const g = mix(nightColor[1], dayColor[1], day);
  const b = mix(nightColor[2], dayColor[2], day);
  return 'rgb(' + r + ',' + g + ',' + b + ')';
}
```

А в отрисовке неба вместо постоянного цвета теперь:

```js
ctx.fillStyle = skyColor();   // цвет меняется каждый кадр!
```

## ✏️ Попробуй сам

1. Ускорь время: поменяй `time += 0.004` на `time += 0.02`. День и ночь будут сменяться
   быстрее!
2. Сделай ночь совсем чёрной: поменяй `nightColor` на `[0, 0, 0]`.
3. Сделай закат розовым: попробуй `dayColor = [255, 150, 120]` и посмотри, что получится.
4. Покажи на экране подпись «День» или «Ночь» в зависимости от того, больше `day` чем `0.5`
   или меньше. (Подсказка: `if (day > 0.5) { ... } else { ... }`.)

## ⚠️ Частые ошибки

- Если время `time` не увеличивать каждый кадр — небо «застынет» и не будет меняться.
- Цвет `rgb(...)` собирается из **чисел от 0 до 255**. Если число будет больше — браузер
  просто не поймёт цвет.

## 💡 Запомни

- **Таймер** — это переменная, которую мы каждый кадр чуть увеличиваем.
- **`Math.sin(time)`** качается туда-сюда — отлично подходит для день/ночь.
- **Интерполяция** (`a + (b - a) * t`) находит цвет посередине между двумя.
