# Урок 08. Первый холст 🎨

## 🎯 Цель урока

Хватит писать только в консоль — пора **рисовать**! Сегодня мы возьмём специальный
прямоугольник на странице, который называется **холст** (`canvas`), и нарисуем на нём
самый первый блок нашего Майнкрафта — квадратик земли.

## 🤔 Что такое холст?

Представь, что у художника есть чистый лист бумаги. Он берёт кисточку, выбирает краску
и рисует. В браузере «лист бумаги» — это тег `<canvas>`, а «кисточка с красками» — это
особый помощник, которого мы называем **контекст** (`ctx`). Сначала мы получаем кисточку,
потом выбираем цвет, а потом рисуем прямоугольник.

## 🧩 Новые слова

- **`<canvas id="game" width="320" height="320"></canvas>`** — холст для рисования.
  У него обязательно указывают ширину и высоту в пикселях.

```js
const canvas = document.getElementById("game"); // нашли холст по его id
const ctx = canvas.getContext("2d");            // взяли кисточку (контекст)
```

- **`ctx.fillStyle`** — выбираем цвет краски (как обмакнуть кисть в баночку).

```js
ctx.fillStyle = "#8b5a2b"; // цвет земли
```

- **`ctx.fillRect(x, y, ширина, высота)`** — рисуем закрашенный прямоугольник.
  `x` и `y` — это где у него левый верхний угол (в пикселях).

```js
ctx.fillRect(0, 0, 32, 32); // квадрат 32 на 32 в левом верхнем углу
```

## 🛠️ Что делаем

Открой `index.html` двойным щелчком — и ты сразу увидишь на странице один коричневый
квадратик. Это первый блок земли нашего будущего мира! Его размер — `32` пикселя, ровно
как мы договорились (`const TILE = 32`).

## ✏️ Попробуй сам

1. Поменяй цвет блока на цвет травы `#5fbf4f` — получишь блок травы.
2. Передвинь блок: поставь его не в углу, а в центре. Подсказка: `ctx.fillRect(100, 100, 32, 32)`.
3. Нарисуй блок побольше — например `64` вместо `32`. Что изменилось?
4. Добавь ещё одну строчку и нарисуй второй квадрат рядом с первым.

## ⚠️ Частые ошибки

- Сначала надо **получить контекст** `ctx`, и только потом рисовать.
- У холста размеры задают **в самом теге** (`width`/`height`), а не только в стилях.
- Цвет — это **текст в кавычках**: `"#8b5a2b"`.

## 💡 Запомни

- Холст `<canvas>` — это место для рисунка, а `ctx` — наша кисточка.
- Порядок всегда такой: выбрать цвет (`fillStyle`) → нарисовать (`fillRect`).
- Координаты считают в пикселях: `x` — вправо, `y` — вниз.

В следующем уроке мы нарисуем не один блок, а **целый ряд** разноцветных блоков с помощью
цикла `for`. Мир начинает оживать! 🧱
