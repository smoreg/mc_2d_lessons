# Урок 35. Загружаем мир 📂

## 🎯 Цель урока

Научиться **доставать** сохранение из сундучка браузера, чтобы мир возвращался — даже после
того, как ты закрыл вкладку и открыл игру заново. Сегодня сохранение наконец-то заработает
по-настоящему!

## 🤔 Достаём записку из сундучка

В прошлом уроке мы положили в сундучок (`localStorage`) записку-текст с нашим миром. Теперь
надо сделать наоборот:

1. **Достать** текст из сундучка — командой `localStorage.getItem`.
2. **Превратить** текст обратно в объект — командой `JSON.parse`.

Это как развернуть подарок: сначала достаём свёрток, потом разворачиваем.

Но есть важный момент: а вдруг сохранения **ещё нет** (ты впервые открыл игру)? Тогда из
сундучка достанется `null` — «пусто, ничего нет». Поэтому перед тем как разворачивать,
обязательно надо **проверить**, что записка вообще есть.

## 🧩 Новые слова

- **`localStorage.getItem(ключ)`** — достаёт текст из сундучка по подписи. Если ничего нет —
  возвращает `null`.

```js
let text = localStorage.getItem('mc2d-save');
```

- **`JSON.parse(текст)`** — превращает текст обратно в объект (противоположность
  `JSON.stringify`).

```js
let data = JSON.parse(text);   // снова объект { world, inventory, player }
console.log(data.player.x);    // можно читать его свойства!
```

- **Проверка на `null`** — `if (text)` сработает, только если текст есть. Если `null` — внутрь
  `if` не зайдём.

- **`try { ... } catch { ... }`** — «попробуй, а если сломается — не падай». Если вдруг текст
  в сундучке испорчен, `JSON.parse` может выдать ошибку. `try/catch` ловит её, и игра не
  ломается.

```js
try {
  let data = JSON.parse(text);   // пробуем развернуть
} catch {
  console.log('Сохранение испорчено :(');   // если не вышло — спокойно идём дальше
}
```

## 🛠️ Что делаем

Открой `index.html`. Поиграй, накопай, нажми **S** (сохранить). А теперь — **обнови страницу**
(F5) или вообще закрой и открой файл заново. Твой мир на месте! 🎉

Когда игра запускается, она первым делом заглядывает в сундучок:

```js
function loadGame() {
  const text = localStorage.getItem(SAVE_KEY);   // достаём текст
  if (!text) return;                              // сохранения нет — играем новый мир
  try {
    const data = JSON.parse(text);               // текст → объект
    world = data.world;                          // восстанавливаем мир
    inventory = data.inventory;                  // и инвентарь
    player.x = data.player.x;                     // и героя
    player.y = data.player.y;
  } catch {
    console.log('Не удалось загрузить сохранение');
  }
}
loadGame();   // вызываем сразу при старте
```

Ещё есть клавиша **L** — загрузить вручную в любой момент, и **N** — начать новый мир.

## ✏️ Попробуй сам

1. Сохрани мир (S), обнови страницу (F5) — убедись, что мир вернулся. Потом нажми **N** —
   мир станет новым.
2. Накопай большую яму, сохрани, перезапусти — яма на месте? Отлично!
3. Сломай сохранение нарочно: F12 → Application → Local Storage → измени значение `mc2d-save`
   на абракадабру вроде `ой!`, обнови страницу. Благодаря `try/catch` игра не упадёт, а просто
   начнёт новый мир.
4. Добавь в `loadGame` строчку `console.log('Загружено:', data)` после `JSON.parse` — посмотри
   в консоли, что именно вернулось.

## ⚠️ Частые ошибки

- Забыть **проверку на `null`**. Если сразу написать `JSON.parse(null)`, будет ошибка. Сначала
  `if (!text) return;`.
- Перепутать `stringify` и `parse`. Запомни: **stringify** — объект **в** строку (сохраняем),
  **parse** — строку **обратно** в объект (загружаем).

## 💡 Запомни

- **`localStorage.getItem(ключ)`** достаёт текст (или `null`, если ничего нет).
- **`JSON.parse(текст)`** превращает текст обратно в объект.
- Всегда **проверяй**, что сохранение есть, и оборачивай разбор в **`try/catch`**.
