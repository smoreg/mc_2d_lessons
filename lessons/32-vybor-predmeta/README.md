# Урок 32. Выбор предмета 🔢

## 🎯 Цель урока

Научиться **выбирать** слот инвентаря клавишами `1`–`9`. Тот блок, что лежит в выбранном
слоте, — это блок «в руке»: именно его мы потом будем ставить.

## 🤔 Как это работает в Майнкрафте

В настоящем Майнкрафте ты жмёшь цифру — и нужный слот подсвечивается. Сделаем так же: нажал
`1` — выбрался первый слот, нажал `3` — третий. Подсвеченный слот сразу видно.

## 🧩 Новые слова

- **Событие `keydown`** — срабатывает, когда нажата клавиша. Мы уже встречали его, когда
  управляли героем.

```js
window.addEventListener('keydown', function (e) {
  console.log('Нажата клавиша:', e.key);
});
```

- **`e.key`** — это **текст** нажатой клавиши: для цифры `1` будет строка `"1"`.
- **`Number("3")`** — превращает текст в число: `"3"` → `3`. Пригодится, чтобы из клавиши
  получить номер слота.
- **`selectSlot(inv, index)`** — запоминает, какой слот выбран:

```js
function selectSlot(inv, index) {
  if (index >= 0 && index < inv.slots.length) {
    inv.selected = index;
  }
}
```

> 💡 Внимание: игрок жмёт `1` (первый слот), а в массиве слоты считаются с `0`. Поэтому
> номер слота — это `Number(e.key) - 1`.

## 🛠️ Что делаем

Открой `index.html`. Внизу — знакомая панель инвентаря. Понажимай клавиши `1`, `2`, `3`… —
подсветка будет перепрыгивать на нужный слот. Наверху написано, какой блок сейчас «в руке».

## ✏️ Попробуй сам

1. Понажимай цифры `1`–`8` и посмотри, как двигается белая подсветка.
2. Нажми `9` — ничего не произойдёт, ведь слотов всего 8. Так и задумано: `selectSlot`
   проверяет, что номер не выходит за край.
3. В коде поменяй блоки в инвентаре (`addBlock`) и понаблюдай, какой блок «в руке» при выборе.
4. Сделай так, чтобы при выборе слота его номер печатался в консоль через `console.log`.

## ⚠️ Частые ошибки

- `e.key` — это **строка** `"3"`, а не число `3`. Чтобы посчитать номер слота, переведи её в
  число: `Number(e.key)`.
- Не забывай про `-1`: клавиша `1` — это слот с индексом `0`.

## 💡 Запомни

- `keydown` + `e.key` — узнаём нажатую клавишу.
- `selectSlot(inv, index)` запоминает выбранный слот, а `inv.selected` показывает, какой он.

Выбирать блок мы умеем. В последнем уроке части соединим всё вместе: **копать**, чтобы
блоки добавлялись, и **ставить** их, тратя из инвентаря! ⛏️🧱
