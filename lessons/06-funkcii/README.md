# Урок 06. Функции — свои команды 🧩

## 🎯 Цель урока

Научиться создавать **свои команды** — функции. Один раз описал, что делать, а потом вызываешь
сколько угодно раз. Например, команду «нанести урон герою» или «напечатать блок».

## 🤔 Рецепт

Функция — это как **рецепт**. Один раз записал: «как испечь торт». Потом можно печь торт хоть
каждый день, не вспоминая шаги заново — просто открываешь рецепт. В программе ты тоже один раз
описываешь команду, а потом просто **вызываешь** её по имени.

## 🧩 Новые слова

- **Объявление функции** — описываем команду. `function`, имя, скобки `( )` и код в `{ }`:

```js
function sayHello() {
  console.log("Привет, герой!");
}

sayHello();   // вызов: теперь команда выполнится
sayHello();   // можно вызывать сколько угодно раз!
```

- **Параметры** — это «ингредиенты», которые мы передаём функции в скобках:

```js
function printBlock(name) {     // name - параметр
  console.log("Это блок:", name);
}

printBlock("трава");   // напечатает: Это блок: трава
printBlock("камень");  // напечатает: Это блок: камень
```

- **`return`** — функция может **вернуть результат**, чтобы мы его использовали дальше:

```js
function takeDamage(health, damage) {
  return health - damage;   // вернём новое здоровье
}

let newHealth = takeDamage(100, 30);   // newHealth станет 70
console.log("Здоровье после удара:", newHealth);
```

## 🛠️ Что делаем

Открой `index.html` в браузере и загляни в консоль (**F12** → **Console**). Программа объявляет
функции `printBlock` (печатает блок) и `takeDamage` (возвращает новое здоровье) и несколько раз
их вызывает.

## ✏️ Попробуй сам

1. Вызови `printBlock` ещё несколько раз с другими блоками: «дерево», «алмаз», «золото».
2. Нанеси герою урон дважды подряд: сначала отними 20, потом ещё 15. Сколько осталось?
3. Сделай функцию `heal(health, amount)`, которая **прибавляет** здоровье и возвращает его.
4. Сделай функцию `greet(name)`, которая печатает «Привет, …!» с переданным именем.

## ⚠️ Частые ошибки

- Объявить функцию — это ещё не вызвать её! Без `printBlock("трава")` команда просто лежит и
  ждёт. Не забывай **скобки** при вызове.
- `return` сразу **завершает** функцию: код после `return` уже не выполнится.
- Если функция должна дать результат — обязательно используй `return`. Без него она вернёт
  «ничего» (`undefined`).

## 💡 Запомни

- Функция — это твоя собственная команда: описал один раз, вызывай много раз.
- Параметры в скобках — это то, что мы передаём функции «на вход».
- `return` возвращает результат наружу.

В следующем уроке научимся хранить **много** значений сразу — в списках (массивах). Например,
весь список блоков мира! 📋
