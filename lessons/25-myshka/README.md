# Урок 25. Мышка 🖱️

## 🎯 Цель урока

Научить игру **слушать мышку**: понимать, куда ты нажал, какой кнопкой (левой или правой)
и на какую клетку мира пришёлся клик. Это первый шаг к копанию и строительству!

## 🤔 Аналогия

Представь, что мир — это большая клетчатая тетрадь, а мышка — твой палец. Компьютер не видит
«клетку» сам по себе. Он знает только, в каком **пикселе** оказался курсор. Наша задача —
перевести пиксели в клетки. Это как перевести метры в шаги: один шаг (клетка) = 32 пикселя.

## 🧩 Новые слова

- **`addEventListener('mousedown', ...)`** — «слушать» нажатие кнопки мыши. Когда нажмут —
  выполнится наша функция.
- **`addEventListener('mousemove', ...)`** — слушать движение мыши.
- **`e.clientX`, `e.clientY`** — координаты курсора на экране в пикселях.
- **`getBoundingClientRect()`** — узнаёт, где именно на странице находится наш холст. Нужно,
  чтобы вычитать «отступ» холста и получить координаты *внутри* canvas.
- **`e.button`** — какая кнопка нажата: `0` — левая, `2` — правая.
- **`contextmenu`** — событие правого клика. Мы его «отменяем», чтобы не вылезало меню браузера.

```js
canvas.addEventListener('mousedown', function (e) {
  const rect = canvas.getBoundingClientRect();
  const cx = Math.floor((e.clientX - rect.left) / TILE); // клетка по горизонтали
  const cy = Math.floor((e.clientY - rect.top) / TILE);  // клетка по вертикали
  console.log('Нажали на клетку', cx, cy);
});
```

> 💡 `Math.floor` округляет вниз. Пиксель 70 при размере клетки 32 даёт `70/32 = 2.18`,
> а `Math.floor(2.18) = 2` — значит, это 2-я клетка.

## 🛠️ Что делаем

Открой `index.html`. Ты увидишь маленький мир из блоков. Наведи мышку — внизу появится подпись,
на какую клетку ты навёл. Кликни левой кнопкой — клетка подсветится зелёным, правой — красным.
А в консоли (F12 → Console) будут печататься координаты клика.

## ✏️ Попробуй сам

1. Поменяй `const TILE = 32;` на `48`. Клетки станут крупнее — проверь, что подсветка
   всё равно попадает точно в клетку.
2. Сделай так, чтобы при правом клике в консоль писалось `"Правый клик!"`.
3. Добавь в `mousemove` строчку `console.log(cx, cy)` и посмотри, как координаты меняются,
   когда водишь мышкой.
4. Поменяй цвет подсветки левого клика на синий (`'#3b6dd2'`).

## ⚠️ Частые ошибки

- Если забыть про `getBoundingClientRect()` и взять просто `e.clientX`, клетки будут «съезжать»,
  когда холст не в самом углу страницы.
- `e.button === 2` — это **правая** кнопка, а не вторая по счёту. Левая — это `0`.

## 💡 Запомни

- Мышка даёт **пиксели**, а нам нужны **клетки** — делим на `TILE` и округляем вниз.
- Левая кнопка — `0`, правая — `2`.
- `getBoundingClientRect()` помогает найти координаты внутри холста.

В следующем уроке мы наконец-то начнём **копать**: по левому клику блок будет исчезать! ⛏️
