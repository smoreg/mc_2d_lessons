# Урок 24. Столкновения с блоками 🧱

## 🎯 Цель урока

Это **самый важный урок** про физику героя! Сейчас наш герой приземляется на невидимый пол. А
мы хотим, чтобы он по-настоящему **стоял на блоках**: не проваливался сквозь землю и не проходил
сквозь стены. После этого урока герой будет вести себя совсем как в настоящей игре.

Не торопись — мы разберём всё по шагам.

## 🤔 Что значит «столкнуться»?

Герой — это прямоугольник. Блоки — это клетки сетки. **Столкновение** — это когда прямоугольник
героя налезает на твёрдый блок. Наша задача:

1. Понять, **пересекает ли** герой хоть один твёрдый блок.
2. Если да — **не пускать** его туда: откатить назад.

Главная хитрость, которую используют почти во всех 2D-играх:

> Двигаем героя **отдельно по X** и **отдельно по Y**.

Почему отдельно? Если двигать сразу и вбок, и вниз, то при столкновении непонятно, что мешает —
стенка сбоку или пол снизу. А когда шаги раздельные, всё ясно:
- столкнулся, двигаясь **по X** → значит упёрся в **стену**;
- столкнулся, двигаясь **по Y** вниз → значит встал на **землю**.

## 🧩 Новые слова

### 1) `isSolid(id)` — твёрдый ли блок

Сквозь воздух (и воду) можно проходить, сквозь остальное — нет.

```js
function isSolid(id) {
  // 0 = воздух, 7 = вода. Всё остальное — твёрдое.
  return id !== 0 && id !== 7;
}
```

### 2) `getBlock(world, x, y)` — какой блок в клетке

```js
function getBlock(world, x, y) {
  // За границей мира считаем, что воздух (0).
  if (y < 0 || y >= world.length)        return 0;
  if (x < 0 || x >= world[0].length)     return 0;
  return world[y][x];
}
```

### 3) `collides(...)` — пересекает ли герой твёрдый блок

Самая важная функция. Герой — прямоугольник от `(px, py)` шириной `w` и высотой `h` (в
клетках). Он может накрывать сразу несколько клеток. Мы проверяем **все клетки**, которые он
задевает: если хоть в одной твёрдый блок — это столкновение.

```js
function collides(world, px, py, w, h) {
  // Левая/правая и верхняя/нижняя клетки, которые задевает прямоугольник.
  const x0 = Math.floor(px);
  const x1 = Math.floor(px + w - 0.001);
  const y0 = Math.floor(py);
  const y1 = Math.floor(py + h - 0.001);

  for (let y = y0; y <= y1; y++) {
    for (let x = x0; x <= x1; x++) {
      if (isSolid(getBlock(world, x, y))) return true;  // нашли твёрдый блок!
    }
  }
  return false;   // ни одного твёрдого блока — путь свободен
}
```

> 💡 Зачем `- 0.001`? Без этого, если правый край героя ровно совпадает с границей клетки,
> функция «зацепит» лишнюю соседнюю клетку и герой застрянет. Маленький отступ это чинит.

## 🛠️ Что делаем — по шагам

Вот сердце урока: в функции `update()` мы двигаем героя **сначала по X, потом по Y**, и после
каждого шага проверяем столкновение.

### Шаг 1. Движение по X

Считаем, куда герой хочет встать. **Пробуем** туда переместиться:

```js
let nextX = player.x + dir * speed;          // куда хотим (dir: -1, 0 или 1)
if (!collides(world, nextX, player.y, w, h)) {
  player.x = nextX;                          // путь свободен — идём
}
// иначе НЕ двигаемся: впереди стена
```

### Шаг 2. Гравитация и прыжок (меняем `vy`)

```js
if (wantJump && player.onGround) {
  player.vy = -jumpPower;       // толчок вверх
  player.onGround = false;
}
player.vy += gravity;           // гравитация тянет вниз
```

### Шаг 3. Движение по Y (самое интересное)

Пробуем сдвинуться по вертикали. Если впереди свободно — двигаемся. Если уперлись —
**откатываем** и разбираемся, что случилось:

```js
let nextY = player.y + player.vy;
if (!collides(world, player.x, nextY, w, h)) {
  player.y = nextY;             // путь свободен (летим/падаем)
  player.onGround = false;
} else {
  // уперлись! Куда двигались?
  if (player.vy > 0) {
    player.onGround = true;     // падали вниз → ВСТАЛИ НА ЗЕМЛЮ
  }
  player.vy = 0;                // обнуляем скорость (пол или потолок остановил)
}
```

Вот и всё! Эти три шага и делают героя «настоящим». Открой `index.html` — герой падает,
встаёт на травку, ходит по неровностям, упирается в холмик и может на него запрыгнуть.

## ⚠️ Частые ошибки

- **Двигать X и Y вместе.** Тогда нельзя понять, где столкновение, и герой застревает в углах.
  Всегда двигай по очереди: сначала X, потом Y.
- **Забыть обнулить `vy`** при столкновении по вертикали — герой будет «дрожать» или
  проваливаться.
- **`onGround` ставим в `true` только при падении вниз** (`vy > 0`). Если упёрся головой в
  потолок (`vy < 0`) — это не земля!
- **Откат вместо «впихивания».** Мы не двигаем героя в стену, а просто **не разрешаем** ход:
  пробуем `nextX`/`nextY` и применяем только если там свободно.

## 💡 Запомни

- Столкновение = герой-прямоугольник накрыл **твёрдый** блок (`collides`).
- Двигаемся **раздельно по X и по Y** — так понятно, стена это или пол.
- Уперся при `vy > 0` → **`onGround = true`** (встал на землю), и `vy = 0`.
