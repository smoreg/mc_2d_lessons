# Урок 31. Панель инвентаря 🎒

## 🎯 Цель урока

Сделать **панель инвентаря** — полоску слотов внизу экрана, в которых лежат блоки и их
количество. Это первый кусочек настоящего игрового интерфейса (его называют UI — от
английского *user interface*, «пользовательский интерфейс»).

## 🤔 Что такое инвентарь

Инвентарь — это рюкзак героя, разбитый на **ячейки-слоты**. В каждом слоте лежит какой-то
блок и написано, сколько его. Чтобы хранить это в коде, нам понадобится сразу несколько
объектов в одном **массиве**.

## 🧩 Новые слова

- **Слот** — это объект `{ blockId, count }`: какой блок и сколько его.

```js
const slot = { blockId: 2, count: 5 };   // 5 блоков земли
```

- **Инвентарь** — объект с массивом слотов и номером выбранного:

```js
const inventory = { slots: [...], selected: 0 };
```

- **`createInventory(size)`** — создаёт инвентарь из `size` пустых слотов:

```js
function createInventory(size) {
  const slots = [];
  for (let i = 0; i < size; i++) {
    slots.push({ blockId: 0, count: 0 });   // 0 = пусто
  }
  return { slots: slots, selected: 0 };
}
```

- **`drawInventory(ctx, inv)`** — функция, которая **рисует** панель слотов внизу холста.

## 🛠️ Что делаем

Открой `index.html`. Под миром появилась **полоса слотов**. В нескольких слотах уже лежат
блоки: внутри каждого занятого слота — цветной квадратик блока, число (сколько штук) и номер
слота в уголке. Первый слот подсвечен белым — он выбранный.

Главное здесь — функция `drawInventory`: она проходит по всем слотам в цикле и для каждого
рисует квадрат, а если в слоте есть блоки — ещё и цветной кубик с числом.

## ✏️ Попробуй сам

1. В коде поменяй число слотов: `createInventory(8)` → `createInventory(5)`. Слотов стало меньше.
2. Положи в инвентарь другой блок: добавь строку `addBlock(inventory, 6, 10);` (10 песка).
3. Поменяй у какого-нибудь слота `count`, например на 99 — увидишь большое число в слоте.
4. Найди в `drawInventory` строку с размером слота `slotSize` и сделай слоты крупнее.

## ⚠️ Частые ошибки

- Слоты лежат в `inventory.slots` — это **массив**, поэтому к ним обращаются по индексу:
  `inventory.slots[0]`.
- Не путай: `selected` — это **номер** выбранного слота (число), а не сам слот.

## 💡 Запомни

- Инвентарь = `{ slots: [{blockId, count}, ...], selected }`.
- `createInventory(size)` делает пустой инвентарь, `drawInventory` его рисует.

Панель есть, но пока выбран всегда первый слот. В следующем уроке научимся **выбирать**
нужный слот клавишами `1`–`9`! 🔢
