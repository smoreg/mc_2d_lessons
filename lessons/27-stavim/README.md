# Урок 27. Ставим блоки 🧱

## 🎯 Цель урока

Научиться **строить**: по **правому клику** ставить блок в пустую клетку. Теперь ты сможешь не
только разрушать, но и создавать — строить домики, башни и мосты!

## 🤔 Аналогия

Ставить блок — это как закрасить пустую клеточку в тетради. Но есть правило: закрашивать можно
**только пустую** клетку. Нельзя поставить блок туда, где уже что-то стоит — иначе ты бы стирал
старый блок, а это уже копание, а не строительство.

## 🧩 Новые слова

- **`placeBlock(grid, x, y, id)`** — поставить блок, но **только если клетка пустая** (воздух).
- Снова используем **`e.button === 2`** — это правый клик.

```js
function placeBlock(grid, x, y, id) {
  if (getBlock(grid, x, y) !== 0) return false;  // клетка занята — не ставим
  setBlock(grid, x, y, id);                       // ставим блок
  return true;
}
```

> 💡 Знак `!==` означает «не равно». Условие `getBlock(...) !== 0` читается так:
> «если в клетке **не** воздух» — значит, она занята, и ставить туда нельзя.

## 🛠️ Что делаем

Открой `index.html`. Теперь работают **обе** кнопки:

- **левая** кнопка — копаем (блок исчезает);
- **правая** кнопка — ставим выбранный блок.

Вверху три кнопки выбора блока — нажми на них, чтобы выбрать, что строить: землю, камень или
дерево. А потом правым кликом ставь блоки в небо и строй что хочешь!

## ✏️ Попробуй сам

1. Построй из дерева простой домик: стены и крышу.
2. В `placeBlock` убери проверку `if (...) return false;` — теперь блоки будут заменять друг
   друга. Это удобно? Верни проверку обратно — так честнее.
3. Добавь четвёртый блок для выбора — траву (id `1`). Подсказка: скопируй одну из кнопок.
4. Сделай блок по умолчанию (`selectedBlock`) не землёй, а камнем (`3`).

## ⚠️ Частые ошибки

- Если ставить блок туда, где уже что-то есть, `placeBlock` вернёт `false` — и ничего не
  произойдёт. Это правильно! Сначала **выкопай**, потом ставь новое.
- Не перепутай кнопки: копание — левая (`0`), постановка — правая (`2`).

## 💡 Запомни

- Ставить блок = записать его номер в **пустую** клетку.
- Перед постановкой всегда проверяем, что там воздух (`getBlock(...) === 0`).
- Левая кнопка копает, правая — строит.

В следующем уроке добавим **дальность**: герой не сможет копать и строить слишком далеко от
себя — совсем как в настоящей игре! 📏
