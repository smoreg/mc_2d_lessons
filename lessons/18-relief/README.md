# Урок 18. Делаем рельеф интереснее ⛰️

## 🎯 Цель урока

Наш мир пока плоский, как стол. Сделаем его живым: добавим **холмы** (поверхность будет
подниматься и опускаться), немного **случайности** для разнообразия и выкопаем маленькую
**пещерку** под землёй.

## 🤔 Аналогия

Настоящая земля не ровная: где-то горка, где-то ямка. Чтобы получить плавные холмы, программисты
часто берут на помощь **волну** — синус. Это такая функция, которая плавно качается вверх-вниз,
как морские волны. Мы используем её, чтобы высота поверхности красиво «гуляла».

## 🧩 Новые слова

- **`Math.sin(число)`** — даёт значение волны: число плавно меняется от -1 до 1. Если подавать
  ему `x`, поверхность будет волниться по столбцам.

```js
let hill = Math.round(2 * Math.sin(x / 3)); // холм высотой примерно от -2 до 2
```

- **`Math.round(число)`** — округляет до целого (нам нужны целые клетки, а не пол-клетки).

- **`Math.random()`** — случайное число от 0 до 1 (как бросок кубика). С его помощью добавим
  немного непредсказуемости:

```js
if (Math.random() < 0.1) {
  // сработает примерно в 1 случае из 10
}
```

- **`Math.floor(число)`** — округляет **вниз** (отбрасывает дробную часть).

## 🛠️ Что делаем

Открой `index.html`. Функция генерации теперь считает для каждого столбца свою высоту
поверхности `top = base + холм`. Из-за синуса получаются плавные холмы. Кое-где случайно
вырастает песок вместо травы. А ещё мы прокопали небольшую пещерку — выемку из воздуха внутри
камня. Обнови страницу несколько раз — из-за случайности мир будет чуть-чуть разным!

## ✏️ Попробуй сам

1. Сделай холмы выше: поменяй `2 * Math.sin(...)` на `3 * Math.sin(...)`. Горки станут круче.
2. Растяни волны: вместо `Math.sin(x / 3)` напиши `Math.sin(x / 6)` — холмы станут длиннее и
   плавнее.
3. Сделай песок более частым: поменяй `< 0.1` на `< 0.3`. Песчаных мест станет больше.
4. Передвинь пещерку: поменяй числа в её цикле и посмотри, куда она переедет.

## ⚠️ Частые ошибки

- Забыть `Math.round` — тогда высота получится дробной, и клетки «съедут».
- Сделать холмы слишком высокими — поверхность может уйти за верх экрана.

## 💡 Запомни

- **`Math.sin`** делает плавные волны — отличный способ нарисовать холмы.
- **`Math.random`** добавляет разнообразие, чтобы мир не был одинаковым.
- Высоту поверхности можно считать **для каждого столбца отдельно**.

Мир стал интереснее, но блоки всё ещё просто одноцветные квадраты. В следующем уроке добавим
**простые текстуры** — мелкие детали, чтобы трава, земля и камень выглядели красивее! 🎨
