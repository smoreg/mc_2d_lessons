# Урок 20. Наш герой 🦸

## 🎯 Цель урока

Сегодня в нашем мире из блоков наконец-то появится **главный герой**! Мы научимся описывать
его как **объект** и рисовать на холсте поверх мира. Пока он будет стоять неподвижно — но это
уже настоящий персонаж, которого скоро мы научим ходить и прыгать.

## 🤔 Кто такой герой для программы?

Для компьютера герой — это не картинка и не живое существо. Это просто **набор чисел**:
где он стоит, какой он ширины и высоты. Удобнее всего хранить такие числа вместе, в одной
«коробочке». Такая коробочка с несколькими подписанными значениями называется **объект**.

Представь анкету героя:

```
Имя:    Герой
x:      5   (на каком столбце клеток он стоит)
y:      8   (на какой строке)
ширина: 0.8 клетки
высота: 1.8 клетки
```

Вот этот «бланк анкеты» в коде и есть объект `player`.

## 🧩 Новые слова

- **Объект** — несколько значений с именами внутри фигурных скобок `{ }`. Каждое значение
  называется **свойство**.

```js
let player = {
  x: 5,        // столбец, где стоит герой (в клетках)
  y: 8,        // строка, где стоит герой
  width: 0.8,  // ширина героя в клетках
  height: 1.8  // высота героя в клетках
};
```

- **Доступ к свойству через точку** — чтобы прочитать или поменять значение, пишем
  `имяОбъекта.свойство`:

```js
console.log(player.x);  // напечатает 5
player.x = 6;           // передвинули героя на клетку правее
```

- **Координаты в клетках, а не в пикселях.** Мир у нас — сетка из клеток по `TILE = 32`
  пикселя. Герой тоже живёт «в клетках». Чтобы нарисовать его на экране, мы умножаем
  координату клетки на `TILE`:

```js
let pixelX = player.x * TILE;  // переводим клетки в пиксели
```

## 🛠️ Что делаем

Открой `index.html` в браузере. Программа создаёт маленький мир с травой и землёй, рисует его,
а потом поверх рисует **красный прямоугольник** — это наш герой! Он стоит на травке и пока
никуда не двигается.

В коде есть функция `drawPlayer()` — её единственная задача нарисовать героя. Хорошо, когда
у каждой функции одна понятная работа.

## ✏️ Попробуй сам

1. Поменяй `x` и `y` у героя (например, `x: 2` или `y: 6`) и обнови страницу — герой
   «телепортируется» в новое место.
2. Сделай героя выше: поменяй `height: 1.8` на `height: 3`. Что изменилось?
3. Поменяй цвет героя. Найди в коде `'#d23b3b'` и поставь, например, `'#2b6fd2'` (синий).
4. Нарисуй герою «глазик»: после отрисовки прямоугольника добавь маленький белый квадратик
   через `ctx.fillRect(...)`.

## ⚠️ Частые ошибки

- Между свойствами объекта ставится **запятая**, а не точка с запятой:
  `{ x: 5, y: 8 }` — правильно.
- Не путай координаты в клетках и в пикселях. Герой стоит на `x: 5` (клетка), а на экране
  это `5 * TILE` пикселей.

## 💡 Запомни

- **Объект** `{ }` хранит несколько значений с именами.
- К свойству обращаемся через **точку**: `player.x`.
- Чтобы нарисовать клеточные координаты, умножаем их на `TILE`.

Герой стоит на месте — скучновато! В следующем уроке мы научимся **слушать клавиатуру**,
чтобы программа узнавала, какие клавиши ты нажимаешь. 🎮
