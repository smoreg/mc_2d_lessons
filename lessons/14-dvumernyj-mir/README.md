# Урок 14. Двумерный мир 🗺️

## 🎯 Цель урока

Научиться хранить целую **карту мира** — не просто список блоков в одну линию, а настоящую
**таблицу** из строк и столбцов. Это самая главная идея всего нашего Майнкрафта: весь мир —
это большая таблица из чисел.

## 🤔 Аналогия

Представь тетрадку в клеточку или шахматную доску. У каждой клетки есть два адреса: в каком
она **столбце** (по горизонтали) и в какой **строке** (по вертикали). Если знаешь оба числа —
ты найдёшь любую клетку.

В обычном массиве (мы их проходили) можно хранить только одну линию:

```js
let line = [0, 0, 1, 1, 3]; // одна строчка блоков
```

А чтобы получилась таблица, нужно сделать **массив из массивов** — каждая строка таблицы это
свой маленький массив, а большой массив хранит все строки.

## 🧩 Новые слова

- **Двумерный массив (2D-массив)** — это массив, внутри которого лежат другие массивы.
  Получается таблица.

```js
let grid = [
  [0, 0, 0], // строка 0
  [0, 0, 0], // строка 1
  [0, 0, 0], // строка 2
];
```

- **`grid[y][x]`** — так мы достаём одну клетку. Сначала выбираем строку `y`, потом в ней
  столбец `x`. Запомни порядок: **сначала y, потом x**!

```js
grid[1][2] = 1; // в строке 1, столбце 2 поставили блок с id 1
console.log(grid[1][2]); // покажет 1
```

- **`массив.length`** — длина массива. У `grid` это число строк, а у `grid[0]` — число
  столбцов.

## 🛠️ Что делаем

Открой `index.html` в браузере (и загляни в консоль через F12 → Console). Программа создаёт
пустую карту мира из воздуха с помощью **двойного цикла** и печатает её размер и саму таблицу.
А на холсте ты увидишь пустую сетку — будущую карту нашего мира.

Двойной цикл — это цикл внутри цикла: внешний бежит по строкам (`y`), внутренний — по
столбцам (`x`). Так мы обходим **каждую** клетку таблицы.

## ✏️ Попробуй сам

1. Поменяй размеры мира: сделай `cols = 5` и `rows = 5`. Сетка станет другой.
2. После создания мира поставь один блок: `grid[2][3] = 1;` и снова напечатай таблицу —
   найди единичку.
3. Напечатай в консоль количество строк (`grid.length`) и количество столбцов в первой строке
   (`grid[0].length`).
4. Попробуй прочитать клетку, которой нет, например `grid[100][100]` — увидишь, что будет
   ошибка. Так бывает, когда выходишь за границу мира.

## ⚠️ Частые ошибки

- Путать порядок: правильно `grid[y][x]` (сначала строка, потом столбец), а не наоборот.
- Забыть, что счёт начинается с **0**: первая строка — это `grid[0]`, а не `grid[1]`.

## 💡 Запомни

- Весь наш мир — это **таблица чисел** `grid[y][x]`.
- Таблицу делают **массивом из массивов**.
- **Двойной цикл** позволяет обойти каждую клетку.
