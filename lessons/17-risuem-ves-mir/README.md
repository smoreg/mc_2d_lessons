# Урок 17. Рисуем весь мир 🖌️

## 🎯 Цель урока

Собрать всё вместе и нарисовать **целый мир из блоков** на экране: небо, землю и камень —
большим красивым полем. И сделать это аккуратно: завести функции `getBlock` и `drawWorld`,
как в настоящей игре.

## 🤔 Аналогия

Представь, что ты раскрашиваешь альбом по клеточкам. Ты идёшь слева направо, сверху вниз, и в
каждую клетку ставишь нужный цвет. Ты не пропускаешь ни одной клетки — поэтому в конце картинка
готова целиком. Компьютер делает то же самое, только очень быстро.

Чтобы клетка таблицы превратилась в место на экране, мы умножаем её номер на размер блока:

```
пиксель по X = x * TILE
пиксель по Y = y * TILE
```

## 🧩 Новые слова

- **Функция `getBlock(world, x, y)`** — аккуратный способ узнать блок в клетке. Если клетка за
  границей мира, вернём воздух (чтобы не было ошибки):

```js
function getBlock(world, x, y) {
  if (x < 0 || y < 0 || x >= world.cols || y >= world.rows) return AIR;
  return world.grid[y][x];
}
```

- **Функция `drawWorld(world)`** — рисует весь мир одним двойным циклом. Один раз написали —
  и пользуемся.

- **`x * TILE`, `y * TILE`** — перевод «номера клетки» в «пиксели на экране». Это связывает
  таблицу с холстом.

## 🛠️ Что делаем

Открой `index.html`. Мы собрали мир в один объект `world` (в нём `cols`, `rows` и сама таблица
`grid`). Функция `drawWorld` проходит по всем клеткам и рисует каждую цветом из справочника.
Холст стал больше — теперь на нём целый мир: голубое небо, зелёная поверхность, коричневая
земля и серый камень внизу.

## ✏️ Попробуй сам

1. Сделай мир шире: поменяй `cols` на 16 и `width` у `<canvas>` на 512. Мир станет длиннее.
2. «Прокопай» дырку прямо в коде: после генерации напиши `world.grid[6][5] = 0;` — появится
   пустая клетка с небом.
3. Поставь камень на поверхность: `world.grid[4][8] = 3;` — будет как валун.
4. Поменяй цвет неба у `<canvas>` (в стиле `background`) на ночной, например `#1a2a4f`.

## ⚠️ Частые ошибки

- Забыть умножить на `TILE`: тогда все блоки нарисуются в одном углу 1×1 пиксель.
- Перепутать ширину холста и количество столбцов: если `cols * TILE` больше ширины холста,
  часть мира не поместится.

## 💡 Запомни

- Весь мир рисуется **одним двойным циклом** по таблице.
- `x * TILE`, `y * TILE` переводят клетку в пиксели.
- Удобно держать мир в объекте `world` и рисовать функцией `drawWorld`.

Пока наш мир плоский, как стол. В следующем уроке сделаем **рельеф интереснее**: добавим холмы
и даже маленькую пещерку! ⛰️
