# Урок 04. Если… то… — принятие решений 🤔

## 🎯 Цель урока

Научить программу **думать** и принимать решения. Например: «**Если** здоровье героя больше
нуля — он жив. **Иначе** — игра окончена». Или: «**Если** хватает камня — строим стену».

## 🤔 Развилка на дороге

Представь, что ты идёшь по лесу в Майнкрафте и видишь развилку: налево — пещера, направо —
деревня. Ты смотришь на условие («ночь или день?») и выбираешь дорогу. Программа делает то же
самое: проверяет условие и выбирает, какой код выполнить.

## 🧩 Новые слова

- **`if` (если)** — выполняет код, **только если** условие верно:

```js
let health = 80;
if (health > 0) {
  console.log("Герой жив!");
}
```

- **`else` (иначе)** — что делать, когда условие **не** верно:

```js
if (health > 0) {
  console.log("Герой жив!");
} else {
  console.log("Game Over 💀");
}
```

- **Сравнения** — так мы задаём вопросы компьютеру:
  - `>` больше, `<` меньше, `>=` больше или равно, `<=` меньше или равно
  - `===` равно (именно **три** знака `=`!), `!==` не равно

```js
console.log(10 > 3);    // true  (правда)
console.log(5 === 5);   // true
console.log(2 === 7);   // false (ложь)
```

- **`true` и `false`** — это «правда» и «ложь». Любое сравнение превращается в одно из них.

- **`&&` (И) и `||` (ИЛИ)** — соединяют два условия:
  - `&&` — верно, когда верны **оба** условия;
  - `||` — верно, когда верно **хотя бы одно**.

```js
let wood = 5;
let stone = 3;
if (wood >= 2 && stone >= 2) {
  console.log("Хватает на постройку верстака!");
}
```

## 🛠️ Что делаем

Открой `index.html` в браузере и загляни в консоль (**F12** → вкладка **Console**). Программа
проверяет, жив ли герой, хватает ли ресурсов на постройку и день сейчас или ночь.

## ✏️ Попробуй сам

1. Поменяй здоровье `let health = 80;` на `0` и обнови страницу (F5) — увидишь «Game Over».
2. Добавь проверку: если здоровье **меньше 30**, печатай «Осторожно, мало здоровья!».
3. Поменяй количество камня и дерева так, чтобы **не** хватало на постройку, и проверь сообщение.
4. Придумай своё условие с `||`, например: «если сейчас ночь **или** идёт дождь — сиди дома».

## ⚠️ Частые ошибки

- Для проверки «равно» нужны **три** знака: `===`. Один знак `=` — это «положить значение»
  (присваивание), а не сравнение!
- Не забывай фигурные скобки `{ }` — внутри них код, который выполнится по условию.
- `true` и `false` пишутся **без кавычек**. `"true"` — это просто текст, а не «правда».

## 💡 Запомни

- `if` проверяет условие, `else` — что делать иначе.
- Сравнения (`>`, `<`, `===`, `!==`) дают `true` или `false`.
- `&&` — нужны оба условия, `||` — достаточно одного.

В следующем уроке научимся **повторять** действия много раз — это циклы. Построим целую
лесенку из блоков, не повторяя код руками! 🔁
