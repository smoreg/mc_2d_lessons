# Урок 09. Цвета и много блоков 🌈

## 🎯 Цель урока

Один блок — это хорошо, но мир Майнкрафта состоит из тысяч блоков! Сегодня научимся
рисовать **много блоков сразу** и сделаем это красиво — с помощью цикла `for`, чтобы
не писать одно и то же сто раз.

## 🤔 Почему цикл, а не сто строк?

Представь, что нужно нарисовать ряд из 10 блоков. Можно написать 10 строчек `fillRect`...
а можно сказать компьютеру: «нарисуй блок, потом сдвинься правее и нарисуй ещё, и так
10 раз». Это и есть **цикл** `for` — наш трудолюбивый помощник, который повторяет команду
сколько нужно.

## 🧩 Новые слова

- **Цикл `for`** — повторяет код несколько раз.

```js
for (let i = 0; i < 10; i = i + 1) {
  // этот код выполнится 10 раз: i будет 0, 1, 2, ... 9
}
```

- **`i`** — счётчик. Он считает, какой это по счёту повтор. Удобно умножать его на `TILE`,
  чтобы каждый блок вставал правее предыдущего:

```js
let x = i * TILE; // блок номер 0 -> x=0, номер 1 -> x=32, номер 2 -> x=64...
```

- **Массив цветов** — список красок, из которого можно брать по очереди:

```js
const colors = ["#5fbf4f", "#8b5a2b", "#9a9a9a"]; // трава, земля, камень
```

## 🛠️ Что делаем

Открой `index.html` — ты увидишь **ряд разноцветных блоков** по горизонтали: трава, земля,
камень, дерево, песок и снова по кругу. Все они нарисованы одним маленьким циклом!

## ✏️ Попробуй сам

1. Сделай ряд длиннее: поменяй `i < 8` на `i < 10`.
2. Добавь в массив `colors` цвет воды `#3a7bd5` и цвет листвы `#3e9b3e`.
3. Сделай так, чтобы блоки рисовались не сверху, а посередине холста (поменяй `y` с `0`
   на, например, `150`).
4. Попробуй нарисовать **второй ряд** ниже первого — добавь ещё один цикл.

## ⚠️ Частые ошибки

- Не забудь фигурные скобки `{ }` — внутри них живёт код, который повторяется.
- `i = i + 1` обязательно, иначе цикл будет крутиться **вечно** (зависнет).
- Цвет берут из массива по номеру: `colors[i]` — обрати внимание на квадратные скобки.

## 💡 Запомни

- `for` повторяет код — не нужно писать одно и то же руками.
- `i * TILE` сдвигает каждый блок на одну клетку правее.
- Цвета удобно хранить в массиве и брать `colors[i]`.

В следующем уроке мы научимся **описывать блок как объект** — с координатами и цветом
в одном «свёртке». Это шаг к настоящему миру из блоков! 📦
