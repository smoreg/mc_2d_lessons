# Урок 28. Дальность действия 📏

## 🎯 Цель урока

Сделать игру честнее: герой не должен копать и строить на другом конце мира! Мы научимся
**измерять расстояние** между героем и клеткой и разрешать копать/ставить, только если она
достаточно близко.

## 🤔 Аналогия

У тебя есть руки, и ты можешь дотянуться только до того, что рядом. До стены на другом конце
комнаты рукой не достать — нужно подойти. Так и герой: у него есть **дальность** (REACH) —
сколько клеток он способен дотянуться. Дальше — никак.

## 🧩 Новые слова

- **Расстояние между двумя точками.** Вспомни школьную «теорему Пифагора» — но не пугайся,
  компьютер посчитает сам. Берём разницу по X и по Y, и:

```js
const dx = clickX - heroX;   // разница по горизонтали
const dy = clickY - heroY;   // разница по вертикали
const dist = Math.sqrt(dx * dx + dy * dy);  // длина прямой между ними
```

- **`Math.sqrt(n)`** — «квадратный корень». Это как раз то, что превращает `dx` и `dy` в
  настоящее расстояние по прямой.
- **`REACH`** — наша дальность в клетках. Если `dist <= REACH` — клетка в пределах руки.

```js
const REACH = 5;   // дотягиваемся на 5 клеток
function withinReach(cx, cy) {
  const dx = cx + 0.5 - heroCenterX;   // +0.5 — берём центр клетки
  const dy = cy + 0.5 - heroCenterY;
  return Math.sqrt(dx * dx + dy * dy) <= REACH;
}
```

> 💡 Мы прибавляем `0.5`, чтобы считать расстояние до **центра** клетки, а не до её угла.
> Так получается ровный круг дальности вокруг героя.

## 🛠️ Что делаем

Открой `index.html`. На карте есть герой (красный квадратик). Вокруг него — круг дальности.
Попробуй копать левым кликом и ставить правым: близко — получится, далеко — нет! Если клетка
слишком далеко, она мигнёт красным.

## ✏️ Попробуй сам

1. Поменяй `const REACH = 5;` на `2`. Теперь дотянуться можно совсем близко. А на `8`?
2. Подвигай героя: поменяй `heroX` и `heroY` в начале кода и посмотри, как сдвинется круг.
3. Сделай так, чтобы при попытке копнуть слишком далеко в консоль писалось `"Слишком далеко!"`.
4. Поменяй цвет круга дальности на жёлтый.

## ⚠️ Частые ошибки

- Не забудь `Math.sqrt`! Без него ты сравниваешь не настоящее расстояние, а «квадрат
  расстояния» — и круг получится неправильным.
- `<=` (меньше или равно), а не `<` — иначе самая дальняя клетка чуть-чуть «не дотянется».

## 💡 Запомни

- Расстояние = `Math.sqrt(dx*dx + dy*dy)`.
- Копать/ставить можно, только если `расстояние <= REACH`.
- Прибавляем `0.5`, чтобы мерить до центра клетки.

В следующем уроке мы красиво **подсветим** клетку под курсором рамкой — и сразу будет видно,
дотянешься ты до неё или нет. ✨
