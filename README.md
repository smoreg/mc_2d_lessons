# 🧱 Майнкрафт 2D на JavaScript — курс для детей

Привет! Это курс, в котором ты шаг за шагом научишься программировать на **JavaScript** и
**сам сделаешь свою игру** — простой двухмерный Майнкрафт прямо в браузере.

Никаких сложных программ устанавливать не надо. Тебе нужны только:

- 🌐 Браузер (Chrome, Firefox, Edge, Safari — любой)
- 📝 Текстовый редактор (подойдёт **VS Code** — он бесплатный)

Каждый урок — это отдельная папка. Внутри урока:

- `README.md` — понятное объяснение: что мы сегодня делаем и почему;
- `index.html` — готовый код, который ты можешь **открыть двойным щелчком** и сразу увидеть результат.

> 💡 **Как работать с уроком:** сначала читай объяснение, потом открывай `index.html` в браузере,
> а потом — открывай тот же файл в редакторе и пробуй что-нибудь поменять. Сломать тут ничего
> нельзя! Если что-то перестало работать — просто верни как было.

---

## 🎮 Что у нас получится в конце

К концу курса у тебя будет своя игра, в которой можно:

- ходить по миру из блоков (земля, трава, камень, дерево…);
- **копать** блоки и **ставить** новые;
- собирать ресурсы в **инвентарь**;
- прыгать, падать (есть гравитация!) и не проваливаться сквозь землю;
- **сохранять** свой мир, чтобы вернуться к нему позже.

И самое главное — ты будешь **понимать**, как всё это устроено, потому что напишешь это сам.

## 🪟 Как запустить готовую игру на Windows

Хочешь просто поиграть в итоговую версию (папка `game/`)? Вот по шагам.

### Шаг 1. Скачать проект

**Способ А — без программ (проще всего):**
1. Открой страницу проекта: <https://github.com/smoreg/mc_2d_lessons>
2. Нажми зелёную кнопку **`Code`** → **`Download ZIP`**.
3. Найди скачанный файл `mc_2d_lessons-master.zip` (обычно в папке «Загрузки»).
4. Щёлкни по нему правой кнопкой → **«Извлечь всё…»** (Extract All) → **«Извлечь»**.

**Способ Б — через Git** (если установлен Git):
```powershell
git clone https://github.com/smoreg/mc_2d_lessons.git
```

### Шаг 2. Запустить игру

Зайди в распакованную папку, открой папку **`game`** и **дважды щёлкни по файлу `index.html`** —
игра откроется в браузере. Всё! 🎮

> 💡 Если файл открылся как текст, а не как игра: щёлкни по `index.html` правой кнопкой →
> **«Открыть с помощью»** → выбери браузер (Chrome, Edge или Firefox).

### Управление

| Клавиши | Действие |
|---------|----------|
| `←` `→` или `A` `D` | идти |
| `↑` / `Пробел` / `W` | прыжок |
| **Левая кнопка мыши** | копать блок |
| **Правая кнопка мыши** | поставить блок |
| `1`…`8` | выбрать блок из инвентаря |
| `S` | сохранить игру |
| `L` | загрузить игру |

### Если сохранение (`S`/`L`) не работает

Некоторые браузеры запрещают сохранение, когда страница открыта напрямую с диска
(адрес начинается с `file:///`). Тогда запусти игру через простой локальный сервер:

**Вариант 1 — Python** (если установлен; проверь командой `py --version`):
1. Открой папку `game` в Проводнике.
2. В адресной строке Проводника напечатай `cmd` и нажми `Enter` — откроется командная строка в этой папке.
3. Введи команду и нажми `Enter`:
   ```powershell
   py -m http.server 8765
   ```
4. Открой в браузере адрес: <http://localhost:8765>
5. Чтобы остановить сервер — вернись в командную строку и нажми `Ctrl + C`.

**Вариант 2 — расширение для VS Code:** установи бесплатное расширение **Live Server**,
открой папку проекта в VS Code, щёлкни по `game/index.html` правой кнопкой →
**«Open with Live Server»**.

## 👩‍🏫 Для преподавателя и родителя

Этот раздел — для взрослого, который ведёт курс. Здесь о том, как объяснять материал, на что
смотреть и как понять, что ребёнок действительно усвоил тему.

### Общий подход

- **Главное правило: меньше лекций, больше «пробуй сам».** Ребёнок учится, когда меняет код и
  видит, что получилось. На каждом уроке есть блок «✏️ Попробуй сам» — это сердце урока, не
  пропускайте его. Читать теорию целиком наизусть не нужно.
- **Темп — индивидуальный.** Один урок может занять от 20 минут до часа. Не гонитесь за
  скоростью: лучше один урок с экспериментами, чем три «пробежки глазами».
- **Ошибки — это нормально и полезно.** Сломать ничего нельзя. Если код перестал работать —
  это отличный момент: открываем консоль (F12 → Console), читаем красную ошибку вместе и ищем
  опечатку. Умение читать ошибки важнее, чем умение писать без ошибок.
- **Связывайте с игрой.** Постоянно напоминайте: «вот это мы потом используем, чтобы герой
  копал/прыгал/сохранялся». Мотивация ребёнка — увидеть свой Майнкрафт.

### Как устроен каждый урок

| Часть README урока | Что с ней делать |
|--------------------|------------------|
| 🎯 Цель | Прочитайте вслух — задаёт, зачем этот урок. |
| 🤔 Аналогия | Главный инструмент объяснения. Сначала аналогия, потом код. |
| 🧩 Новые слова | Новая конструкция JS. Покажите пример руками, не торопитесь. |
| 🛠️ Что делаем | Откройте `index.html`, посмотрите результат **вместе**. |
| ✏️ Попробуй сам | Ребёнок меняет код сам. Вы — рядом, но не вместо него. |
| ⚠️ Частые ошибки | Профилактика типичных затыков. |
| 💡 Запомни | Короткое резюме в конце. Спросите своими словами. |

### Как объяснять ключевые темы (шпаргалка)

- **Переменные (урок 02).** Аналогия — подписанная коробка. `let` — коробку можно
  переложить, `const` — заколочена. Частая путаница: имя без кавычек, текст в кавычках.
- **Условия `if/else` (урок 04).** «Если дождь — берём зонт, иначе — кепку». Обратите внимание
  на `===` (сравнение) против `=` (присваивание) — это ошибка №1 у новичков.
- **Циклы (урок 05).** «Повтори 10 раз». Покажите, что цикл — это способ не писать одно и то
  же руками. Сразу обсудите, как НЕ сделать бесконечный цикл (`while`).
- **Функции (урок 06).** Аналогия — кнопка/заклинание: нажал — сработало. Параметры — это
  «что подаём на вход», `return` — «что отдаёт обратно».
- **Массивы (урок 07).** Список/полка с пронумерованными ячейками. Главный сюрприз: счёт
  начинается с **0**, а не с 1.
- **Canvas (уроки 08–13).** Холст — это лист в клетку. Координаты: X — вправо, **Y — ВНИЗ**
  (не вверх, как на уроках математики!). Это важный момент, проговорите его отдельно.
- **Двумерный массив — мир (уроки 14–17).** Таблица: `grid[y][x]`. Сначала строка (y), потом
  столбец (x). Полезно нарисовать сетку на бумаге и вписать числа.
- **Гравитация и столкновения (уроки 23–24).** Самая трудная пара уроков. Объясняйте по шагам:
  сначала «скорость падения растёт каждый кадр», потом «перед движением проверяем, не упрёмся ли
  в блок». Если буксует — задержитесь здесь подольше.
- **Сохранение (уроки 34–35).** `JSON.stringify` — «сфотографировать» мир в текст,
  `JSON.parse` — «распаковать» обратно. Покажите сам текст сохранения — детям нравится.

### Как проверять прогресс ребёнка

Не устраивайте экзамен. Вместо этого после урока попросите сделать **одно** из:

1. **Объясни своими словами**, что нового он сегодня узнал (тема из «💡 Запомни»).
2. **Внеси своё изменение**, которого не было в заданиях (поменяй цвет, число, добавь блок).
   Если может сам — тема усвоена.
3. **Найди и почини ошибку**: заранее сломайте одну строчку (уберите `;`, кавычку или опечатку
   в имени) и попросите починить. Отлично тренирует чтение ошибок в консоли.
4. **Предскажи результат**: «как думаешь, что выведет эта строчка?» — а потом проверьте.

Зелёный сигнал «можно дальше»: ребёнок может **сам** изменить код урока и **объяснить**, что
именно поменялось. Если только повторяет за вами — повторите урок на другом примере.

### Папка `game/` — готовая игра и автотесты

В папке [`game/`](game/) лежит **финальная версия игры**, к которой ведёт весь курс (можно
открыть `game/index.html` и сразу играть — это хороший «маяк» цели для ребёнка). Логика игры
разбита на модули в `game/js/` и **покрыта автотестами**.

Для взрослого, кто хочет проверить целостность кода (ребёнку это не обязательно):

```bash
npm install      # один раз — поставить инструменты
npm test         # прогнать автотесты игровой логики
npm run lint     # проверить код линтером (ESLint)
```

Тесты покрывают мир и блоки, копание/постановку, инвентарь, физику героя и сохранение —
то есть всю «честную» игровую логику.
